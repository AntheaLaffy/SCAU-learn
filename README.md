## 如何使用

- 你可以直接点击上面的课程目录，在仓库中按科目浏览资料。
- 仓库内还包含一个静态站点版本，相关页面与资源位于 [`.website/`](./.website)。
- 如果你只是想快速找试卷、答案或习题，优先从对应课程目录进入会更直接。

## 本地运行网站

网站使用 Vite 和 TypeScript 构建：

```bash
cd .website
npm install
npm run dev
```

执行 `npm run build` 会在 `.website/dist/` 生成可部署的静态文件。推送到 `main` 分支后，GitHub Actions 会自动构建并发布到 GitHub Pages。
