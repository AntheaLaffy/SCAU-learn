# 用户手册

这里整理的是 `SCAU-learn` 资料站的基本使用方式，方便第一次进入网站的同学快速上手。

## 如何浏览资料

1. 左侧导航栏按照课程分类组织资料页面。
2. 点击具体课程后，右侧会加载对应的试卷、答案、课件或说明文档。
3. 点击左上角站点标题，可以随时回到欢迎页。

## 如何搜索

- 左侧顶部的搜索框支持按课程名或页面标题筛选菜单。
- 搜索只影响导航展示，不会修改仓库中的任何文件。

## 资料说明

- 站点页主要提供索引和下载入口，原始文件保存在仓库目录中。
- 如果某个页面暂时没有完整整理，后续会继续补充。
- 遇到链接失效或资料有误时，可以通过 GitHub Issue 或 PR 反馈。
