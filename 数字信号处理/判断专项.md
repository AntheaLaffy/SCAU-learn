### **二、系统（线性、时不变、因果、稳定、卷积）**

**1. 零输入导致零输出的系统是线性系统。**
*   **答案：错。**
*   **解析：** “零输入产生零输出”只是线性系统的一个必要条件，而非充分条件。一个系统可能满足零输入零输出，但不满足可加性或齐次性（例如 $y(n) = x^2(n)$，输入为0输出为0，但它是非线性的）。

**2. 任何一个系统的输出 y(n) 都可以用输入 x(n) 与单位抽样响应 h(n) 的卷积来表示。**
*   **答案：错。**
*   **解析：** 只有 **LSI（线性移不变）系统** 才可以。

**3. 判断下面的系统是否为因果系统：**
1.  $y(n)=nx(n)$：**是**。（输出仅取决于当前输入 $x(n)$）
2.  $y(n)=x(n+2)+ax(n)$：**不是**。（输出取决于将来时刻 $n+2$ 的输入）
3.  $y(n)=x(n^3)$：**不是**。（例如 $n=-2$ 时，取决于 $x(-8)$，是过去；但若 $n=2$ 时，取决于 $x(8)$，是将来。对于一般定义，只要存在反例即非因果）。
4.  $y(n)=x(-n)$：**不是**。（例如 $n=-1$ 时，取决于 $x(1)$，即将来输入）。
5.  $y(n)=x(n)\sin(n+2)$：**是**。（输出仅取决于当前输入 $x(n)$，$\sin(n+2)$ 只是一个随时间变化的系数）。

### **四、频域分析 (DTFT、DFT、FFT)**

**4. 利用 DFT 可以对连续信号频谱进行精确分析。**
*   **答案：错。**
*   **解析：** DFT 存在栅栏效应、频谱泄漏和混叠现象，是对连续频谱的近似采样。

**5. 序列 $x(n)$ 的 N 点 DFT 是 $x(n)$ 的 Z 变换在单位圆上的 N 点等间隔采样。**
*   **答案：对。**

**6. 将 DFS 的时域、频域各取主值序列，可构成 DFT 变换对。**
*   **答案：对。**

**7. 将 DFT 用作频谱分析时，要想提高频率分辨率，可以将时间序列补零，从而增加 DFT 的点数，达到分辨相近频率分量的目的。**
*   **答案：错。**
*   **解析：** 补零只能增加频谱采样的密度（栅栏效应减小），改善视觉效果，但不能提高物理分辨率。物理分辨率由信号的有效记录长度决定。

**8. 对时间序列 x(n) 补若干个零后，频谱的计算分辨率提高，即频谱的采样间隔变小。**
*   **答案：对。**
*   **解析：** 注意区分“计算分辨率”（采样间隔 $2\pi/N$）和“物理分辨率”。补零确实让频谱点更密了。

**9. 线性移位与圆周移位的操作过程是相同的。**
*   **答案：错。**
*   **解析：** 线性移位是数据左右移动，空出补零；圆周移位是移出的数据从另一端补回来。

**10. 当循环卷积区间长度大于或等于线性卷积长度时，循环卷积结果等于线性卷积。**
*   **答案：对。**

**11. 离散傅里叶变换中的卷积运算是线性卷积。**
*   **答案：错。**
*   **解析：** DFT 对应的是圆周卷积（循环卷积）。

**12. 一个信号输入到系统之后，其输出的运算过程即为线性卷积。**
*   **答案：对。**
*   **解析：** 物理系统的实际响应过程是线性卷积。

### **五、IIR 滤波器**

**13. FIR 数字滤波器一定是个稳定的系统。**
*   **答案：对。**
*   **依据：** 因为 FIR 数字滤波器其单位脉冲响应 $h(n)$ 是个有限长序列。有限长序列的 z 变换收敛域是整个 z 平面（可能除去 $z=0$ 或 $z=\infty$），肯定包含单位圆。因此，FIR 数字滤波器一定是一个稳定的系统。

**14. FIR 数字滤波器不存在输出到输入的反馈，即 n 时刻的输出 y(n) 与 n 时刻之前的输出无关，只跟输入有关。**
*   **答案：对。**
*   **依据：** FIR 系统的差分方程形式决定了其输出仅由当前和过去的输入加权和组成，不包含 $y(n-k)$ 项。

**15. 用双线性变换法设计 IIR DF 时，预畸并不能消除变换中产生的所有频率点的非线性畸变。**
*   **答案：对。**
*   **解析：** 预畸变只是校正了关键频率点（如截止频率），整个频率轴的非线性映射关系依然存在。

**16. 采用双线性变换法设计 IIR DF 时，如果设计出的模拟滤波器具有线性幅度响应特性，那么转换后的数字滤波器也具有线性幅度响应特性。**
*   **答案：错。**
*   **解析：** 由于频率轴的非线性压缩 $\omega = 2\arctan(\frac{\Omega T}{2})$，模拟域的线性形状映射到数字域会发生弯曲。

**17. 脉冲响应不变法和双线性变换法都能够将 S 平面的左半平面映射到 z 平面的单位圆内。**
*   **答案：对。**

**18. 脉冲响应不变法使模拟角频率和数字角频率建立线性关系。**
*   **答案：对。**

**19. 双线性变换法使 s 平面和 z 平面建立一一映射关系。**
*   **答案：对。**

### **六、FIR 滤波器**

**20. 四种FIR数字滤波器的相位特性与h(n)的值有关。**
*   **答案：错。**
*   **解析：** 线性相位 FIR 的相位特性公式为 $\theta(\omega) = -\frac{N-1}{2}\omega + \beta$。其线性斜率仅取决于滤波器长度 $N$，截距 $\beta$ 仅取决于对称类型（偶对称或奇对称），与 $h[n]$ 的具体数值大小无关。

**21. 第三类线性相位FIR DF的h（n）共有7个样值，必有h（3）=0。**
*   **答案：对。**
*   **解析：** 第三类为奇对称，中心点 $n = (N-1)/2 = 3$。根据奇对称性质 $h[3] = -h[7-1-3] = -h[3]$，即 $2h[3]=0$，故 $h[3]=0$。

**22. 窗口法设计出的线性相位FIR DF是因果稳定的。**
*   **答案：对。**

**23. 线性相位FIR DF窗口设计法的关键是窗口大小。**
*   **答案：对。**
*   **解析：** 窗口大小直接决定了过渡带的宽度，是满足指标的关键参数。

**24. 矩形窗口法设计线性相位的FIR数字滤波器时，增加窗口宽度可以增加正肩峰的大小。**
*   **答案：错。**
*   **解析：** 增加窗口宽度 N 只能减小过渡带宽度，肩峰（过冲）大小主要取决于窗函数的类型（形状），矩形窗始终约为 9%。

**25. 用矩形窗设计线性相位的FIR低通滤波器，主瓣宽度越小，过渡带宽（ 越小 ）。**
*   **答案：对（填空式判断）。**
*   **解析：** 主瓣宽度与 N 成反比，过渡带宽度与主瓣宽度成正比。主瓣越窄，过渡带越陡峭（越窄）。
