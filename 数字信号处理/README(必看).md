## 3. 备考与考试指南

### 题型分布 (2025参考)
- 选择题、填空题、判断题
- 解释题、计算题
- *注：每年题型可能会有微调*

### 备考策略
1.  **题库是关键**：鉴于大部分题目来自《总复习题库》，建议考前刷一遍，并在打印版上做好索引/标记，方便考场速查。
2.  **关于计算**：本课程考试**计算量很小**，无需携带计算器。
3.  **题目风格**：考察直白，基本没有“弯弯绕绕”的难题。题库中涉及超大计算量、书写繁琐的题目考到的概率极低，重点掌握基础概念即可。
