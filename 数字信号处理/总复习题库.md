### 第一 离散序列与系统
### 1. 什么是模拟信号？
**定义：** 在**时间**和**幅值**（数值）上都是**连续**的信号。
**解释：**
*   **时间连续：** 信号在任何一个时间点都有定义，没有间断。
*   **幅值连续：** 信号的大小可以是任意实数，具有无限的精度，没有最小的单位限制。
*   **物理实例：** 麦克风输出的电压变化、热电偶输出的温度电压。

### 2. 什么是离散信号？
**定义：** 在**时间**上是**离散**（不连续）的，但在**幅值**上仍然是**连续**的信号。
**解释：**
*   **时间离散：** 信号只在特定的时刻（例如第1秒、第2秒）存在，时间轴上是一系列的点，而不是一条线。通常记作序列 $x[n]$。
*   **幅值连续：** 在这些特定的时刻点上，信号的数值仍然是精确的数学实数，未经过四舍五入。
*   **数学意义：** 它是连接模拟信号和数字信号的数学桥梁。

### 3. 什么是数字信号？
**定义：** 在**时间**上是**离散**的，且在**幅值**上也是**离散**（被量化）的信号。
**解释：**
*   **时间离散：** 同上，只在特定时刻采样。
*   **幅值离散：** 信号的数值不能是任意数，必须属于一个有限的集合（例如只能是整数）。
*   **计算机表示：** 在计算机中，它最终表现为由0和1组成的二进制编码。

### 4. 为什么不用真正的数字信号处理，而是用离散信号处理？
**核心原因：** 为了数学计算的**线性**和**简便性**。
*   **数字信号处理（非线性）：** 如果在数学推导中考虑“量化误差”（即数值的四舍五入），系统会变成**非线性系统**。非线性系统的数学分析极其复杂，很难得出通用的公式。
*   **离散信号处理（线性）：** 数学上假设数值是精确的（忽略量化误差），这样系统就是**线性系统**。我们可以利用成熟的线性代数、卷积、傅里叶变换等工具进行完美的设计和分析。
*   **结论：** 只要计算机的字长（位数）足够多（如32位或64位），量化带来的误差就极小。因此，我们用**离散时间信号理论**来设计算法，而在硬件上用**数字信号**来实现，两者的结果在工程上被视为一致。

### 5. 如何将模拟信号转换成数字信号？
通过 **A/D 转换器（模数转换器）**，过程包含三个步骤：
1.  **采样（Sampling）：** 将时间连续变为时间离散。每隔固定时间间隔读取一次信号值。
2.  **量化（Quantization）：** 将幅值连续变为幅值离散。将采样到的精确数值映射到最近的固定刻度值上。
3.  **编码（Coding）：** 将量化后的数值转换成二进制代码（0和1）。

### 6. 如何将非电信号转成电信号？
通过 **传感器（Sensor/Transducer）**。
**解释：** 传感器是一种物理装置，它能感受被测量的物理量（如声音、压力、光强、温度），并将其按一定规律转换成可用的电信号（电压、电流或电阻变化）。

### 7. 模拟信号处理和数字信号处理在实现上有什么不同？
*   **模拟信号处理：** 依靠**硬件电路的物理连接**。通过电阻、电容、电感、运算放大器等电子元件的组合，利用元件的物理特性直接对电压/电流波形进行运算（如积分、微分、滤波）。
*   **数字信号处理：** 依靠**软件算法的数学计算**。通过CPU、DSP芯片或FPGA，将信号作为一串数字，进行加法、乘法和逻辑运算。

### 8. 数字信号处理的优点？
1.  **高可靠性与稳定性：** 也就是抗干扰能力强。数字电路只区分0和1，不受环境温度漂移、元件老化等物理因素影响。
2.  **高灵活性：** 改变系统功能只需修改软件代码，无需更改硬件电路。
3.  **可大规模集成：** 可以将极其复杂的处理系统集成在一个微小的芯片中。
4.  **易于存储和传输：** 数字数据可以无损复制、存储在硬盘中或通过网络传输，不会随时间衰减。

### 9. 数字信号处理的缺点？
1.  **频带范围受限（Aliasing/混叠）：** 受“奈奎斯特采样定理”限制，能够处理的最高频率取决于采样速度。如果信号频率过高而采样不够快，会发生**混叠**（高频信号被错误地识别为低频信号），导致失真。
2.  **系统复杂性与延迟：** 对于极其简单的任务（如简单的音量调节），引入A/D转换、处理器、D/A转换会增加成本和处理时间的延迟。

### 10. 什么情况下会采用模拟信号处理？
1.  **极高频信号：** 当信号频率极高（如微波、射频前端），超出了现有A/D转换器的采样能力时。
2.  **极低成本与简单应用：** 当系统非常简单，不需要复杂算法，且对成本极其敏感时（如简单的模拟滤波器、收音机）。
3.  **高功率接口：** 在驱动大功率负载（如扬声器、电机）的最终输出级，通常需要模拟电路进行功率放大。

### 11. 数字信号处理的精度由谁决定？
由 **字长（Word Length / 位数）** 决定。
1.  **A/D转换器的位数：** 决定了输入信号的原始分辨率（例如16位精度高于8位）。
2.  **处理器的运算位数：** 决定了计算过程中的累积误差。位数越多（如64位浮点 vs 16位定点），运算过程中的截断和舍入误差就越小，精度越高。
### 12. 什么是序列？
**定义：** 序列是对**离散时间信号**的数学表示。
它是一个由有序数值组成的集合，通常记作 $x[n]$。其中 $n$ 是整数，代表离散的时间点（或序号），$x[n]$ 代表该时间点上的信号数值。

### 13. 根据离散时间信号的长度，可以把序列分成哪些类别？
主要分为 **有限长序列** 和 **无限长序列**。
**无限长序列**又细分为以下三类：
1.  **右边序列：** 信号在某时刻 $N_1$ 之前全为0（即当 $n < N_1$ 时，$x[n]=0$）。
2.  **左边序列：** 信号在某时刻 $N_2$ 之后全为0（即当 $n > N_2$ 时，$x[n]=0$）。
3.  **双边序列：** 信号在 $n$ 为正值和负值时都有定义，向正负无穷延伸。

### 14. 视频中对序列相加的一个应用是什么？
序列相加的一个重要应用是：
**利用相加运算改进被加性随机噪声干扰的观测数据的质量。**
（*解释：通常指“信号平均”，通过多次测量并将信号相加，随机噪声会互相抵消变小，而有用信号会增强，从而提高信噪比。*）

### 15. 序列的移位（延迟与超前）
*   **$x(n-m)$**（当 $m$ 为正数时）：表示序列 $x(n)$ 逐项依次**右移** $m$ 位。这代表时间上的**延迟**（Delay）。
*   **$x(n+m)$**（当 $m$ 为正数时）：表示序列 $x(n)$ 逐项依次**左移** $m$ 位。这代表时间上的**超前**（Advance）。

### 16. 连续LTI系统和离散LTI系统卷积的不同？
两者计算系统的输出响应都使用卷积，但数学形式不同：
*   **连续线性时不变（LTI）系统：** 使用 **卷积积分**（Convolution Integral）。是对连续时间变量 $\tau$ 进行积分运算。
*   **离散线性时不变（LTI）系统：** 使用 **卷积和**（Convolution Sum）。是对离散整数变量 $m$ 进行求和运算。

### 17. 卷积和计算的四个步骤？
根据你提供的文本，这四个步骤的标准流程是：
1.  **翻转（Folding）：** 将 $h(m)$ 关于纵轴翻转，得到 $h(-m)$。
2.  **移位（Shifting）：** 将翻转后的序列 $h(-m)$ 移动 $n$ 位，得到 $h(n-m)$。（$n>0$ 右移，$n<0$ 左移）。
3.  **相乘（Multiplication）：** 将原序列 $x(m)$ 与移位后的序列 $h(n-m)$ 在相同的 $m$ 值处对应相乘。
4.  **相加（Summation）：** 将所有相乘的结果累加起来，得到该时刻的输出 $y(n)$。

### 18. 计算题：求 $y[-1]$
**题目数据：**
*   $x[n] = \{2, -3, 4, 1\}$，对应范围 $-1 \le n \le 2$
    *   即：$x[-1]=2, x[0]=-3, x[1]=4, x[2]=1$
*   $h[n] = \{-3, 5, -6, 4\}$，对应范围 $-2 \le n \le 1$
    *   即：$h[-2]=-3, h[-1]=5, h[0]=-6, h[1]=4$

**计算目标：** $y[-1]$
**公式：** $y[-1] = \sum_{m} x[m] \cdot h[-1-m]$

**详细步骤：**
我们需要找到所有满足条件的 $m$，使得 $x[m]$ 和 $h[-1-m]$ 都有非零值。

1.  **当 $m = -1$ 时：**
    *   $x[-1] = 2$
    *   $h[-1 - (-1)] = h[0] = -6$
    *   乘积 = $2 \times (-6) = -12$

2.  **当 $m = 0$ 时：**
    *   $x[0] = -3$
    *   $h[-1 - 0] = h[-1] = 5$
    *   乘积 = $(-3) \times 5 = -15$

3.  **当 $m = 1$ 时：**
    *   $x[1] = 4$
    *   $h[-1 - 1] = h[-2] = -3$
    *   乘积 = $4 \times (-3) = -12$

4.  **当 $m = 2$ 时：**
    *   $x[2] = 1$
    *   $h[-1 - 2] = h[-3] = 0$ (超出 $h$ 的定义范围)
    *   乘积 = 0

**最后求和：**
$y[-1] = (-12) + (-15) + (-12) = -39$

**答案：**
**$y[-1] = -39$**

### 19. 在线性时不变（LTI）系统中，卷积运算主要用于什么？
**答案：** 用于求输入信号通过系统后的**输出响应**。
**解释：** 如果已知系统的单位脉冲响应 $h[n]$ 和输入信号 $x[n]$，系统的输出 $y[n]$ 就是这两个序列的卷积：$y[n] = x[n] * h[n]$。

### 20. 序列的分解（偶部/奇部，实部/虚部）
**答案：**
*   **偶部与奇部的关系（共轭对称与共轭反对称）：**
    任何序列 $x[n]$ 都可以分解为共轭对称分量 $x_e[n]$（偶部）和共轭反对称分量 $x_o[n]$（奇部）之和：
    $$x[n] = x_e[n] + x_o[n]$$
    其中（参考图片2）：
    *   **偶部：** $x_e[n] = \frac{1}{2} [x[n] + x^*[-n]]$
    *   **奇部：** $x_o[n] = \frac{1}{2} [x[n] - x^*[-n]]$

*   **实部与虚部的关系：**
    任何序列也可以表示为实部 $x_r[n]$ 与虚部 $x_i[n]$ 之和：
    $$x[n] = x_r[n] + j \cdot x_i[n]$$
    其中：
    *   **实部：** $x_r[n] = \frac{1}{2} [x[n] + x^*[n]]$
    *   **虚部：** $x_i[n] = \frac{1}{2j} [x[n] - x^*[n]]$

### 22. 单位取样序列 $\delta[n]$ 是什么样的序列？
**答案：** $\delta[n]$ 是一个在 $n=0$ 处幅度为 **1**，在其他处幅度为 **0** 的**现实序列**。
**解释：** 它在计算机和离散数学中是真实存在的，可以直接定义和存储。

### 23. $\delta[n]$ 和 $\delta(t)$ 的区别？
**答案：**
*   **$\delta[n]$（离散）：** 是一个具体的数。在 $n=0$ 时值为1，是一个**有限值**。它是物理上可实现的。
*   **$\delta(t)$（连续）：** 是一种数学模型（狄拉克$\delta$函数）。定义为脉宽趋于0，幅度趋于 $\infty$，但积分面积为1。它是一个**数学极限**，物理上无法产生真正的 $\infty$ 幅度信号。

### 24.u(n)是什么序列？u(-n)代表的含义？
答案：
#### 1. $u(n)$：单位阶跃序列 (Unit Step Sequence)
$u(n)$ 被称为**单位阶跃序列**。它是离散时间系统分析中最常用的基本信号之一。

*   **数学定义：**
    $$u(n) = \begin{cases} 1, & n \ge 0 \\ 0, & n < 0 \end{cases}$$
    这意味着在时刻 $n=0$ 及之后的所有整数时刻，序列的值都为 1；而在 $n=0$ 之前的时刻，值全部为 0。
#### 2. $u(-n)$：翻转单位阶跃序列 (Time-Reversed Unit Step Sequence)
$u(-n)$ 是 $u(n)$ 以纵轴（$n=0$）为中心的**反褶（翻转）**序列。

*   **数学定义：**
    根据 $u(n)$ 的定义，将变量替换为 $-n$：
    $$u(-n) = \begin{cases} 1, & -n \ge 0 \implies n \le 0 \\ 0, & -n < 0 \implies n > 0 \end{cases}$$
    这意味着在 $n=0$ 及之前的所有负整数时刻，序列的值为 1；而在 $n > 0$ 的正半轴，值全部为 0。

### 25. 单位取样序列 $\delta[n]$ 如何表示任意矩形序列 $R_N(n)$？
**答案：**
矩形序列 $R_N(n)$ 可以看作是 $N$ 个移位的单位取样序列的叠加。
**公式：**
$$R_N(n) = \sum_{m=0}^{N-1} \delta(n-m)$$
**解释：** 即在 $0, 1, ..., N-1$ 这些位置上，每个位置都有一个幅度为1的脉冲。

### 26. 推导数字域频率 $\omega$、模拟域频率 $\Omega$ 及线频率 $f$ 的关系

**推导过程：**
1.  设模拟信号为正弦波：$x_a(t) = \sin(\Omega t) = \sin(2\pi f t)$。
2.  进行采样，采样间隔为 $T$（采样频率 $f_s = 1/T$）。
3.  将离散时间变量 $t$ 替换为 $nT$，得到离散序列：
    $$x[n] = x_a(nT) = \sin(\Omega nT) = \sin(2\pi f nT)$$
4.  数字信号的标准形式为 $x[n] = \sin(\omega n)$。
5.  对比上述两式，括号内的系数必须相等：
    $$\omega n = \Omega nT$$
6.  消去 $n$，得到关系式：
    *   **$\omega = \Omega T$**
    *   因为 $\Omega = 2\pi f$ 且 $T = 1/f_s$，代入得：
    *   **$\omega = 2\pi f \cdot \frac{1}{f_s} = 2\pi \frac{f}{f_s}$**

### 27. 数字域角频率 $\omega$ 值的大小表示什么？
**答案：** 表示信号的**归一化频率**，即信号实际频率 $f$ 与采样频率 $f_s$ 的比值关系（再乘以 $2\pi$）。
**解释：** 它反映了序列值变化的快慢。$\omega$ 越大（在 $0$ 到 $\pi$ 范围内），序列振荡越快。

### 28. 填空：数字域频率对应关系
*   当 $\omega = 0$ 时，表示信号的线频率 $f =$ **0** Hz（直流分量）。
*   当 $\omega = 2\pi$ 时，表示信号的线频率 $f =$ **$f_s$** Hz（采样频率）。
    *(注：在数字域中，$\omega=2\pi$ 和 $\omega=0$ 是等价的，这体现了频率的周期性)*

### 29. 如何判断正弦序列的周期性？
**答案：**
计算数字频率 $\omega$ 与 $2\pi$ 的比值（即 $\frac{\omega}{2\pi}$ 或 $\frac{2\pi}{\omega}$）。
*   如果结果是**有理数**（即可以写成两个整数之比，分数），则是**周期序列**。
*   如果结果是**无理数**，则是**非周期序列**。

### 30. 连续正弦信号抽样后一定是周期序列吗？抽样时间间隔 T 和连续正弦信号的周期 T0 之间应该是什么关系才能使所得到的抽样序列仍为周期序列？
**答案：** **不一定**。
**条件：** 只有当抽样时间间隔 $T$ 与连续正弦信号的周期 $T_0$ 之比为**有理数**时，得到的抽样序列才是周期序列。
**关系式：**
$$\frac{T}{T_0} = \frac{k}{N} \quad (\text{k, N 为整数})$$
或者说，信号频率 $f_0$ 与采样频率 $f_s$ 的比值必须是有理数。

#### 31. 为什么不同的正弦信号采样后会变成一样的序列？
*   **条件：** 当两个连续正弦信号的频率之差是**采样频率 $f_s$ 的整数倍**时。
*   **数学解释：** 假设采样频率是 $100\text{Hz}$。那么 $10\text{Hz}$ 的信号和 $110\text{Hz}$ 的信号，在采样点上的数值是完全重合的。计算机分不清谁是谁，这就是“多义性”。

#### 32. 什么是混叠 (Aliasing)？
*   **定义：** 高频信号被错误地“伪装”成了低频信号。
*   **现象：** 本来频率很高的信号（超过了采样频率的一半），采样后在频谱上“折叠”到了低频区，导致信号失真，无法还原。

#### 33. 信号不产生混叠的条件是什么？
*   **条件：** 必须满足**奈奎斯特采样定理**。即采样频率 $f_s$ 必须大于信号最高频率 $f_{max}$ 的两倍。
*   **公式：** $f_s \ge 2 f_{max}$。

#### 34. 信号在时域被采样，其频域会发生什么变化？
*   **核心口诀：** **时域离散，频域周期延拓**。
*   **解释：** 只要你在时间上把信号切成一片片的（离散化），在频谱上，原本的频谱形状就会不断复制、粘贴（周期性重复）。

#### 35. 什么是采样定理？
*   **定义：** 为了能从采样信号中无失真地恢复出原模拟信号，采样频率必须大于信号最高频率的2倍。
*   **工程实践：** 理论上是 $>2$ 倍，但实际工程中为了留有余地（因为滤波器不是完美的），通常取 **3-5倍**。

#### 36. 抗混叠前置滤波的作用是什么？
*   **作用：** “安检员”。在采样之前，先把那些高于折叠频率（$f_s/2$）的高频噪音或干扰信号滤除掉。
*   **目的：** 防止这些高频成分在采样后混入低频区（发生混叠）。它本质上是一个**低通滤波器**。

#### 37. 抗混叠滤波器是模拟的还是数字的？
*   **答案：** **模拟滤波器**。
*   **原因：** 因为它必须在 A/D 转换（采样）**之前**工作。此时信号还是连续的模拟信号，还没进电脑，所以必须用硬件模拟电路来实现。

#### 38. 内插函数的公式是什么？
$$ h(t-mT) = \frac{\sin[\frac{\pi}{T}(t-mT)]}{\frac{\pi}{T}(t-mT)} $$
*   **通俗名称：** **Sinc 函数**（辛格函数）或 **抽样函数**。
*   **本质：** 这是一个理想低通滤波器的时域响应。

#### 39. 内插函数的特点是什么？
![[Pasted image 20260110190006.png]]
1.  **归一性：** 在中心点（采样点 $t=mT$）处，函数值为 **1**。
2.  **零交点：** 在其他所有的采样时刻（$t = (m \pm k)T$, $k$为整数），函数值都恰好为 **0**。
    *   **意义：** 这保证了在恢复信号时，当前采样点的值不会受到其他采样点的影响（无码间串扰）。

#### 40. 内插函数是如何实现信号的恢复的？
![[Pasted image 20260110190116.png]]
*   **原理：** **卷积**（加权叠加）。
*   **过程：**
    1.  每一个采样点 $g[nT]$ 都激发出一个 Sinc 波形（内插函数）。
    2.  这个 Sinc 波形的高度（权重）由该采样点的数值决定。
    3.  **叠加：** 将所有这些高高低低的 Sinc 波形加在一起。
    4.  **结果：** 在采样点之间，这些波形的“尾巴”互相抵消或增强，最终合成出一条平滑的连续曲线 $\hat{g}_a(t)$。

#### 41. 什么是折叠频率？
*   **答案：** 采样频率的一半（$f_s / 2$）。
*   **意义：** 这是不发生混叠所能允许的最高信号频率。超过这个频率的信号，在频谱图上会像折纸一样“折叠”回低频区。

## 四种系统性质

### 1. 线性 (Linearity)

**最基础的理解：** 线性系统就像一个“讲道理”的系统。它满足两个条件：**可加性** 和 **齐次性**。

#### (1) 可加性 (Additivity)
*   **通俗解释：** 如果你把两个不同的信号分别输入系统，得到两个输出。那么，当你把这两个信号加起来再输入系统时，得到的输出就等于之前那两个输出的简单相加。
*   **数学表示：**
    *   如果 $x_1[n] \rightarrow y_1[n]$
    *   如果 $x_2[n] \rightarrow y_2[n]$
    *   那么 $x_1[n] + x_2[n] \rightarrow y_1[n] + y_2[n]$

#### (2) 齐次性 (Homogeneity)
*   **通俗解释：** 如果你把一个信号放大几倍再输入系统，得到的输出也仅仅是原来的输出信号放大相同的倍数。
*   **数学表示：**
    *   如果 $x[n] \rightarrow y[n]$
    *   那么 $a \cdot x[n] \rightarrow a \cdot y[n]$ （$a$ 是任意常数）

#### (3) 线性系统的完整定义 (叠加原理)
一个系统是线性的，当且仅当它同时满足可加性和齐次性。这两者可以合并为一个式子：
*   **如果 $a_1 x_1[n] + a_2 x_2[n] \rightarrow a_1 y_1[n] + a_2 y_2[n]$，则系统是线性的。**

#### 为什么线性很重要？
*   **分析简化：** 我们可以把任何复杂的输入信号分解成很多简单的基本信号（比如单位脉冲信号），然后分别计算系统对这些基本信号的响应，最后把这些响应加起来就是总的输出。这就是**卷积**的基础。
*   **数学工具：** 傅里叶变换、Z变换等强大的数学工具都建立在线性系统的基础上。

#### 例子：
*   **线性系统：** $y[n] = 2x[n]$ (放大器), $y[n] = x[n] + x[n-1]$ (平均器)
*   **非线性系统：**
    *   $y[n] = x^2[n]$ (平方运算，不满足齐次性：$a x[n] \rightarrow (a x[n])^2 = a^2 x^2[n] \neq a y[n]$)
    *   $y[n] = x[n] + 5$ (加常数，不满足可加性：$x_1[n]+x_2[n]+5 \neq (x_1[n]+5) + (x_2[n]+5)$)
    *   $y[n] = \cos(x[n])$ (不满足任何一个)

### 2. 时不变性 (Time-Invariance)

**最基础的理解：** 时不变系统就是“不老不朽”、“不随时间改变设置”的系统。它的行为不会随着时间的推移而改变。

#### 定义：
*   如果一个系统对某个输入 $x[n]$ 产生输出 $y[n]$，那么当输入信号发生**时间上的延迟**时，输出信号也会发生**同样的时间延迟**。
*   **数学表示：**
    *   如果 $x[n] \rightarrow y[n]$
    *   那么 $x[n - n_0] \rightarrow y[n - n_0]$ （$n_0$ 是任意整数延迟）

#### 为什么时不变性很重要？
*   **行为稳定：** 无论你什么时候把信号输入系统，系统都会以同样的方式处理它。
*   **卷积的基础：** 线性时不变（LTI）系统是数字信号处理中最重要的一类系统，它们的输出可以通过**卷积**来计算。

#### 例子：
*   **时不变系统：** $y[n] = x[n] + x[n-1]$ (系统的处理规则不随时间变)
*   **时变系统：** $y[n] = n \cdot x[n]$ (系统增益会随时间 $n$ 变化，比如在 $n=1$ 时放大1倍，在 $n=10$ 时放大10倍，它的处理规则在变)

### 3. 因果性 (Causality)

**最基础的理解：** 因果系统就是“没有预知能力”、“不看未来”的系统。它在某一时刻的输出，只取决于当前时刻和过去时刻的输入，而不会受到未来时刻输入的影响。

#### 定义：
*   对于任何时刻 $n_0$，系统的输出 $y[n_0]$ 只依赖于输入 $x[k]$ 在 $k \le n_0$ 时的值。
*   **通俗解释：** 你现在做的决定，只能基于你现在和过去看到的信息，不能基于你还没发生的事情。

#### 为什么因果性很重要？
*   **物理实现：** 所有的**实时物理系统**都必须是因果的。你不可能在未来事件发生之前就对其做出响应。
*   **实际应用：** 实时音频处理、通信系统、控制系统等都要求是因果的。

#### 例子：
*   **因果系统：**
    *   $y[n] = x[n]$ (当前输出取决于当前输入)
    *   $y[n] = x[n] + x[n-1]$ (当前输出取决于当前和过去的输入)
*   **非因果系统：**
    *   $y[n] = x[n+1]$ (当前输出取决于未来时刻 $n+1$ 的输入)
    *   $y[n] = x[n-1] + x[n+1]$ (同时依赖过去和未来)
    *   *注意：* 虽然非因果系统在物理上无法实时实现，但在**离线处理**（比如处理一段已经录好的音频）时，我们可以利用非因果系统来获得更好的处理效果，因为它可以看到“未来”的数据。

### 4. 稳定性 (Stability)

**最基础的理解：** 稳定系统就是“不会失控”、“不会爆炸”的系统。如果你给它一个有限的输入，它会给出一个有限的输出。

#### 定义 (BIBO 稳定性 - Bounded Input, Bounded Output)：
*   如果一个系统是稳定的，那么对于任何**有界的输入信号**（即输入信号的幅度始终在一个有限范围内），其产生的**输出信号也必须是有界的**（即输出信号的幅度也始终在一个有限范围内）。
*   **数学表示：**
    *   如果 $|x[n]| \le B_x < \infty$ (输入有界)
    *   那么必须有 $|y[n]| \le B_y < \infty$ (输出有界)

#### 为什么稳定性很重要？
*   **安全与可靠：** 实际系统必须稳定，否则一个小的输入可能导致系统输出无限增大，造成设备损坏或系统崩溃。
*   **可预测性：** 保证系统在正常工作范围内不会出现异常行为。

#### 对于 LTI 系统，判断稳定性的条件：
*   一个LTI系统是BIBO稳定的，当且仅当其**单位脉冲响应 $h[n]$ 是绝对可和的**。
*   **数学表示：** $\sum_{k=-\infty}^{\infty} |h[k]| < \infty$

#### 例子：
*   **稳定系统：**
    *   $y[n] = x[n]$
    *   $y[n] = 0.5x[n-1]$
    *   $y[n] = x[n] + 0.5x[n-1]$
*   **不稳定系统：**
    *   $y[n] = \sum_{k=0}^n x[k]$ (累加器/积分器，如果输入是常数1，输出会一直增大，无限)
    *   $y[n] = 2y[n-1] + x[n]$ (如果 $y[-1]=1, x[n]=0$，输出会指数增长，无限)


当一个系统同时满足**线性**和**时不变性**时，它就被称为 **LTI 系统**，这是数字信号处理中最常研究和应用的一类系统，因为它们可以用**卷积**进行完美描述。

### 第二部分 Z变换

### 1. Z变换的意义 & 公式

*   **DTFT（离散时间傅里叶变换）有些信号算出来不收敛**。比如一个越来越大的信号 $2^n u[n]$，它的能量是无穷大。
    *   **Z变换的物理意义：** 为了解决这个问题，Z变换在傅里叶变换的 $e^{-j\omega n}$ 基础上，乘上了一个衰减因子 $r^{-n}$。
*   **公式：**
    $$X(z) = \mathcal{Z}[x(n)] = \sum_{n=-\infty}^{\infty} x(n) z^{-n}$$
    *   这里的 $z$ 是一个复变量：$z = r e^{j\omega}$（包含模长 $r$ 和角度 $\omega$）。

### 2. Z变换与 DTFT 是什么关系？

*   DTFT 是 Z 变换的一个特例。序列在单位圆上的Z变换为序列的傅氏变换DTFT。
*   **详细解释：**
    *   Z 变换是在整个复平面（Z平面）上跑的。
    *   DTFT 只是 Z 变换在 **单位圆**（半径 $r=1$ 的圆）上的取值。
    *   **数学联系：** 当 $z$ 的模长 $|z| = r = 1$ 时，即 $z = e^{j\omega}$，代入 Z 变换公式，就变成了 DTFT 公式。
    *   **结论：** **序列在单位圆上的 Z 变换 = 序列的 DTFT。**

### 3. Z变换的收敛域（ROC）的含义是什么？
![[Pasted image 20260110201933.png]]
*   **定义：** Region of Convergence (ROC)。
*   **含义：** Z变换是一个无穷级数求和。无穷级数不是什么时候都能算出有限值的。
    *   **收敛域就是：** 让 $X(z)$ 这个级数求和结果**有限值/绝对可和** 的那些 $z$ 值的集合。
    *   **通俗理解：** Z 变换不是哪里都有定义的，只有在收敛域这个“安全区”内，Z 变换才有意义。
*   **充要条件：** $\sum |x(n)z^{-n}| < \infty$。

### 4 & 5. 推导$X(z) = \sum_{n=0}^{\infty} a^n z^n$和$X(z) = \sum_{n=0}^{\infty} a^n z^{-n}$收敛条件

这里利用了**等比级数求和公式**：$\sum_{n=0}^{\infty} q^n = \frac{1}{1-q}$，收敛条件是公比 $|q| < 1$。

*   **右边序列（因果序列）：** $x(n) = a^n u(n)$
    *   Z变换变成：$\sum_{n=0}^{\infty} (a z^{-1})^n$
    *   公比是 $a z^{-1} = \frac{a}{z}$。
    *   收敛要求：$|\frac{a}{z}| < 1 \Rightarrow |a| < |z|$。
    *   **结论：** 收敛域在某圆的**外部**（$|z| > |a|$）。

*   **左边序列（反因果序列）：** $x(n) = -a^n u(-n-1)$
    *   这部分对应 $n$ 为负数的情况。
    *   收敛要求公比翻转。
    *   **结论：** 收敛域在某圆的**内部**（$|z| < |a|$）。

*   **阿贝尔定理（预备知识）：** 简单来说，幂级数的收敛域通常是一个**圆环**（Ring）。

### 6. 有限长序列、左边序列、右边序列、双边序列的收敛域大概的形状是怎样的？
![[Pasted image 20260110202130.png]]
收敛域（ROC）总是由以原点为中心的圆围成的区域：
1.  **有限长序列：**
    *   **形状：** 整个 Z 平面（除了可能的原点 $0$ 或无穷远 $\infty$）。
    *   *原因：* 有限项求和，只要 $z$ 不取让某一项变无穷大的值，和就是有限的。
2.  **右边序列（Right-sided）：**
    *   **形状：** 某个圆的**外部** ($|z| > R_{x-}$)。
    *   *例子：* 从 $n=0$ 开始往右延伸的信号。
3.  **左边序列（Left-sided）：**
    *   **形状：** 某个圆的**内部** ($|z| < R_{x+}$)。
    *   *例子：* 从 $n=-1$ 开始往左延伸的信号。
4.  **双边序列（Two-sided）：**
    *   **形状：** **环状区域**（Donut shape，两个圆之间）。
    *   *原因：* 它是左边序列和右边序列的结合，收敛域是两者的交集。

### 7 如果有限长序列在n<0时有取值，那么收敛域是否包含0或∞？
*    如果序列在 $n < 0$ 有值（比如 $x(-1)z^1$）。
    *   当 $z \to \infty$ 时，$z^1$ 会趋向无穷大。
    *   **结论：** 收敛域**不包含 $\infty$**。
### 8. 如果有限长序列在n>0时有取值，那么收敛域是否包含0或∞？
*    如果序列在 $n > 0$ 有值（比如 $x(1)z^{-1} = \frac{x(1)}{z}$）。
    *   当 $z = 0$ 时，分母为 0，不成立。
    *   **结论：** 收敛域**不包含 $0$**。

### 9. 什么是因果序列？因果序列Z变换的收敛域是否包含无穷大？
*   **定义：** 只有在 $n \ge 0$ 时才有值，在 $n < 0$ 时全为 0 的序列。
*   **收敛域特点：**
 ![[Pasted image 20260110202710.png]]
    1.  它是右边序列，所以是**圆外** ($|z| > R$)。
    2.  因为它没有 $n < 0$ 的项（没有 $z$ 的正次幂），所以在 $z = \infty$ 处不会炸。
    3.  **结论：** 收敛域**包含无穷远点 $\infty$**。

### 10. 求 x(n) =$\delta(n)$ 的 Z 变换及收敛域

*   **计算：**
    $$X(z) = \sum_{n=-\infty}^{\infty} \delta(n) z^{-n}$$
    *   因为 $\delta(n)$ 只有在 $n=0$ 时等于 1，其他时候都是 0。
    *   所以求和里只有一项：$1 \times z^{-0} = 1 \times 1 = 1$。
*   **结果：** $X(z) = 1$。
*   **收敛域：** 常数 1 永远是有限的，所以收敛域是**整个 Z 平面** ($0 \le |z| \le \infty$)。

### 11. 求 $x(n) = 2^n u(n) - 3^n u(-n-1)$ 的 Z 变换及收敛域。
**第一部分（右边序列）：** $x_1(n) = 2^n u(n)$
*   **公式套用：** $\sum_{n=0}^{\infty} (2z^{-1})^n$
*   **求和结果：** $\frac{1}{1 - 2z^{-1}} = \frac{z}{z-2}$
*   **收敛条件：** $|2z^{-1}| < 1 \Rightarrow |z| > 2$ （圆外）

**第二部分（左边序列）：** $x_2(n) = -3^n u(-n-1)$
*   这是标准的左边序列形式。
*   **公式套用：** 图片中的手写过程利用了变量代换（令 $m=-n$）或者直接套用左边序列公式。
*   **结果：** $\frac{1}{1 - 3z^{-1}} = \frac{z}{z-3}$
    *   *注意：* 这里手写笔记推导的是正项级数，最后结果是 $\frac{z}{z-3}$。
*   **收敛条件：** $|3z^{-1}| > 1 \Rightarrow |z| < 3$ （圆内）

**合并（求交集）：**
*   第一部分要求：$|z| > 2$
*   第二部分要求：$|z| < 3$
*   **总收敛域：** 取交集，即 **$2 < |z| < 3$**（一个圆环）。

**最终结果：**
$$X(z) = \frac{z}{z-2} + \frac{z}{z-3}$$
收敛域：$2 < |z| < 3$
**总结这道题：** 一个向外扩散（$>2$），一个向内收缩（$<3$），中间夹住的环形区域就是收敛域。

### 12. 利用线性性质，推导出 $x(n)=\cos(\omega_0 n)u(n)$ 的 z 变换

**解：**

根据欧拉公式，余弦信号可以表示为指数信号的和：
$$ \cos(\omega_0 n) = \frac{1}{2} (e^{j\omega_0 n} + e^{-j\omega_0 n}) $$

因此，$x(n)$ 可以写为：
$$ x(n) = \frac{1}{2} e^{j\omega_0 n} u(n) + \frac{1}{2} e^{-j\omega_0 n} u(n) $$

利用 z 变换的线性性质 $Z[ax_1(n) + bx_2(n)] = aX_1(z) + bX_2(z)$，以及指数序列的常用变换对 $Z[a^n u(n)] = \frac{1}{1-az^{-1}}$ (收敛域 $|z| > |a|$)：

1.  第一项 $e^{j\omega_0 n} u(n)$ 的 z 变换为：
    $$ \frac{1}{1 - e^{j\omega_0} z^{-1}} $$
2.  第二项 $e^{-j\omega_0 n} u(n)$ 的 z 变换为：
    $$ \frac{1}{1 - e^{-j\omega_0} z^{-1}} $$

将两者相加：
$$ X(z) = \frac{1}{2} \left[ \frac{1}{1 - e^{j\omega_0} z^{-1}} + \frac{1}{1 - e^{-j\omega_0} z^{-1}} \right] $$

通分合并：
$$ X(z) = \frac{1}{2} \frac{(1 - e^{-j\omega_0} z^{-1}) + (1 - e^{j\omega_0} z^{-1})}{(1 - e^{j\omega_0} z^{-1})(1 - e^{-j\omega_0} z^{-1})} $$

整理分子：
$$ \text{分子} = 2 - (e^{j\omega_0} + e^{-j\omega_0})z^{-1} = 2 - 2\cos(\omega_0)z^{-1} $$

整理分母：
$$ \text{分母} = 1 - (e^{j\omega_0} + e^{-j\omega_0})z^{-1} + e^{j\omega_0}e^{-j\omega_0}z^{-2} = 1 - 2\cos(\omega_0)z^{-1} + z^{-2} $$

代回原式：
$$ X(z) = \frac{1}{2} \frac{2 - 2\cos(\omega_0)z^{-1}}{1 - 2\cos(\omega_0)z^{-1} + z^{-2}} $$

**最终结果：**
$$ X(z) = \frac{1 - \cos(\omega_0)z^{-1}}{1 - 2\cos(\omega_0)z^{-1} + z^{-2}}, \quad |z| > 1 $$

### 13. 利用线性和移位性质，求序列 $x(n)=u(n)-u(n-3)$ 的 z 变换

**解：**

已知单位阶跃序列 $u(n)$ 的 z 变换为：
$$ Z[u(n)] = \frac{1}{1-z^{-1}}, \quad |z| > 1 $$

利用 z 变换的**时移性质**（Time-Shifting Property）：若 $Z[x(n)] = X(z)$，则 $Z[x(n-k)] = z^{-k}X(z)$。

对于 $u(n-3)$，其 z 变换为：
$$ Z[u(n-3)] = z^{-3} \cdot \frac{1}{1-z^{-1}} $$

利用**线性性质**：
$$ X(z) = Z[u(n)] - Z[u(n-3)] = \frac{1}{1-z^{-1}} - \frac{z^{-3}}{1-z^{-1}} $$

**最终结果：**
$$ X(z) = \frac{1 - z^{-3}}{1 - z^{-1}} = 1 + z^{-1} + z^{-2}, \quad |z| > 0 $$
*(注：该序列为有限长序列 \{1, 1, 1\}，收敛域为整个 z 平面除去 z=0 点)*

### 14. 证明：若 $X(z)=Z[x(n)]$，$R_{x-} < |z| < R_{x+}$，则 $Z[x^*(n)]=X^*(z^*)$，$R_{x-} < |z| < R_{x+}$

**证明：**

根据 z 变换的定义：
$$ X(z) = \sum_{n=-\infty}^{\infty} x(n) z^{-n} $$

我们需要求 $x^*(n)$ 的 z 变换，记为 $Y(z)$：
$$ Y(z) = Z[x^*(n)] = \sum_{n=-\infty}^{\infty} x^*(n) z^{-n} $$

现在考察 $X^*(z^*)$ 的表达式。先写出 $X(z^*)$，再取共轭：
$$ X(z^*) = \sum_{n=-\infty}^{\infty} x(n) (z^*)^{-n} $$
$$ X^*(z^*) = \left[ \sum_{n=-\infty}^{\infty} x(n) (z^*)^{-n} \right]^* $$

由于求和与共轭运算可以交换（假设级数收敛），且 $(ab)^* = a^* b^*$：
$$ X^*(z^*) = \sum_{n=-\infty}^{\infty} x^*(n) \left( (z^*)^{-n} \right)^* $$

注意到 $\left( (z^*)^{-n} \right)^* = \left( (z^*)^{-1} \right)^{*n} = (z^{-1})^n = z^{-n}$，或者更直观地：$((z^*)^{-n})^* = (z^{-n})^* {}^* = z^{-n}$。

因此：
$$ X^*(z^*) = \sum_{n=-\infty}^{\infty} x^*(n) z^{-n} $$

这正是 $Z[x^*(n)]$ 的定义式。

**关于收敛域：**
原级数收敛条件为 $R_{x-} < |z| < R_{x+}$。
新级数 $X^*(z^*)$ 的自变量是 $z$。在变换过程中，我们实际上是对 $z^*$ 进行操作。
原变换收敛要求变元模长在区间内，即 $R_{x-} < |z^*| < R_{x+}$。
由于复数共轭的模长相等 $|z^*| = |z|$，因此收敛域条件依然是：
$$ R_{x-} < |z| < R_{x+} $$

**证毕。**

### 15. z 反变换常用的三种方法是哪些？

**答：**

1.  **部分分式展开法 (Partial Fraction Expansion Method)**：将 $X(z)$ 分解为简单的低阶分式之和，利用常用变换对求逆。
2.  **幂级数展开法 / 长除法 (Power Series Expansion / Long Division Method)**：将 $X(z)$ 展开为 $z$ 的幂级数（$z^{-1}$ 或 $z$ 的多项式），系数即为 $x(n)$。
3.  **留数法 / 围线积分法 (Residue Method / Contour Integration Method)**：利用柯西留数定理，通过计算围线积分求得 $x(n)$。

### 16. 解释两个留数定理公式的不同之处及第二个公式的使用条件

**公式 (1)：** $x(n) = \sum_k \text{Res}[X(z)z^{n-1}]_{z=z_k}$
**公式 (2)：** $x(n) = - \sum_m \text{Res}[X(z)z^{n-1}]_{z=z_m}$

**不同之处：**
*   **求和对象不同**：
    *   公式 (1) 是对围线 $C$ **内部**的所有极点 $z_k$ 求留数之和。这通常对应于 $X(z)$ 的极点。
    *   公式 (2) 是对围线 $C$ **外部**的所有极点 $z_m$ 求留数之和。

**第二个公式的使用条件：**
*   该公式基于广义柯西留数定理（整个复平面上所有极点的留数之和为0，包括无穷远点）。
*   **使用条件**：通常当围线外部的极点数目少于内部极点数目，或者计算外部极点留数更简便时使用。
*   **特别注意**：公式 (2) 成立的前提通常假设 $X(z)z^{n-1}$ 在无穷远处的留数为 0（即 $\text{Res}[X(z)z^{n-1}]_{z=\infty} = 0$）。如果无穷远处有非零留数，完整的公式应该是：
    $$ x(n) = - \sum_{z_m \in \text{outside}} \text{Res}[X(z)z^{n-1}]_{z=z_m} - \text{Res}[X(z)z^{n-1}]_{z=\infty} $$
    题目中的公式 (2) 隐含了无穷远点留数为0的情况，或者 $z_m$ 包含了无穷远点。

### 17. $X(z) = \frac{1-2z^{-1}}{z^{-1}-2}, \quad |z| > \frac{1}{2}$，求 $x(n)$

**解：**

首先整理 $X(z)$ 的表达式，使其符合标准形式。
$$ X(z) = \frac{1 - 2z^{-1}}{z^{-1} - 2} $$

我们可以通过多项式除法或代数变形来化简。
$$ \frac{1 - 2z^{-1}}{z^{-1} - 2} = \frac{-2(z^{-1} - 2) - 3}{z^{-1} - 2} = -2 - \frac{3}{z^{-1} - 2} $$

整理分式部分：
$$ - \frac{3}{z^{-1} - 2} = \frac{3}{2 - z^{-1}} = \frac{3}{2(1 - \frac{1}{2}z^{-1})} = \frac{3}{2} \cdot \frac{1}{1 - \frac{1}{2}z^{-1}} $$

所以：
$$ X(z) = -2 + \frac{3}{2} \frac{1}{1 - \frac{1}{2}z^{-1}} $$

根据收敛域 $|z| > \frac{1}{2}$，说明序列是因果（右边）序列。
利用常用变换对：
1.  常数 $A \leftrightarrow A\delta(n)$
2.  $\frac{1}{1-az^{-1}} \leftrightarrow a^n u(n)$ （当 $|z|>|a|$）

进行反变换：
$$ x(n) = -2\delta(n) + \frac{3}{2} \left(\frac{1}{2}\right)^n u(n) $$

**最终结果：**
$$ x(n) = -2\delta(n) + 3 \left(\frac{1}{2}\right)^{n+1} u(n) $$
*(注：写成 $\frac{3}{2}(\frac{1}{2})^n u(n)$ 亦可)*

### 18. 设 $X(z) = \frac{z^2}{(4-z)(z-\frac{1}{4})}, \quad \frac{1}{4} < |z| < 4$，求 $x(n)$

**解：**

首先将 $X(z)$ 整理为关于 $z$ 的标准部分分式形式。
$$ X(z) = \frac{z^2}{-(z-4)(z-\frac{1}{4})} $$

采用 $\frac{X(z)}{z}$ 进行部分分式展开：
$$ \frac{X(z)}{z} = \frac{z}{-(z-4)(z-\frac{1}{4})} = \frac{A}{z-4} + \frac{B}{z-\frac{1}{4}} $$

计算系数 $A$ 和 $B$：
1.  $A = \left. \frac{z}{-(z-\frac{1}{4})} \right|_{z=4} = \frac{4}{-(4 - 0.25)} = \frac{4}{-3.75} = -\frac{4}{15/4} = -\frac{16}{15}$
2.  $B = \left. \frac{z}{-(z-4)} \right|_{z=\frac{1}{4}} = \frac{0.25}{-(0.25 - 4)} = \frac{0.25}{3.75} = \frac{1/4}{15/4} = \frac{1}{15}$

所以：
$$ \frac{X(z)}{z} = -\frac{16}{15} \frac{1}{z-4} + \frac{1}{15} \frac{1}{z-\frac{1}{4}} $$
$$ X(z) = -\frac{16}{15} \frac{z}{z-4} + \frac{1}{15} \frac{z}{z-\frac{1}{4}} $$

根据收敛域 $\frac{1}{4} < |z| < 4$ 判断序列的时域特性：
*   对于极点 $z=4$：收敛域 $|z| < 4$，对应**左边序列（反因果）**。
    变换对：$\frac{z}{z-a} \leftrightarrow -a^n u(-n-1)$
*   对于极点 $z=\frac{1}{4}$：收敛域 $|z| > \frac{1}{4}$，对应**右边序列（因果）**。
    变换对：$\frac{z}{z-a} \leftrightarrow a^n u(n)$

进行反变换：
1.  第一项：$-\frac{16}{15} \left[ -4^n u(-n-1) \right] = \frac{16}{15} 4^n u(-n-1)$
2.  第二项：$\frac{1}{15} \left( \frac{1}{4} \right)^n u(n)$

**最终结果：**
$$ x(n) = \frac{1}{15} \left( \frac{1}{4} \right)^n u(n) + \frac{16}{15} 4^n u(-n-1) $$

### 19. $X(z) = \frac{3z^{-1}}{(1-3z^{-1})^2}, \quad |z| > 3$，求 $x(n)$

### 第三部分 **离散时间傅里叶变换DTFT**

**1. u(n)是什么序列？u(-n)代表的含义？**
*   **u(n)** 称为**单位阶跃序列**。它的定义是：当 $n \ge 0$ 时，取值为 1；当 $n < 0$ 时，取值为 0。在信号处理中，它常用于表示信号的“单边性”，即让信号从 $n=0$ 时刻开始存在。
*   **u(-n)** 是 u(n) 的**时间反转**序列。它的含义是：当 $n \le 0$ 时，取值为 1；当 $n > 0$ 时，取值为 0。

**2. 请写出离散时间傅立叶正变换与逆变换的公式。**
*   **正变换 (DTFT)：**
    $$X(e^{j\omega}) = \sum_{n=-\infty}^{\infty} x(n) e^{-j\omega n}$$
*   **逆变换 (IDTFT)：**
    $$x(n) = \frac{1}{2\pi} \int_{-\pi}^{\pi} X(e^{j\omega}) e^{j\omega n} d\omega$$

**3. 离散时间傅立叶逆变换表示的含义是什么？**
*   它表示离散时间信号 $x(n)$ 可以被分解为无穷多个复指数信号 $e^{j\omega n}$ 的加权积分。
*   换句话说，逆变换通过在 $[-\pi, \pi]$ 区间内对频谱函数 $X(e^{j\omega})$ 进行积分，将频域中的各个频率成分合成回时域信号。

**4. 为什么用求和符号求离散时间傅立叶正变换？而在离散时间傅立叶反变换公式中用的是积分公式？**
*   **正变换用求和 ($\sum$)：** 因为输入信号 $x(n)$ 是**离散**的时间序列，变量 $n$ 取整数，所以在计算时是对一个个离散的采样点进行累加。
*   **逆变换用积分 ($\int$)：** 因为 DTFT 得到的频谱 $X(e^{j\omega})$ 是关于角频率 $\omega$ 的**连续**函数，要从连续的频谱中恢复信号，必须对连续变量 $\omega$ 进行积分运算。

**5. 单位样本序列 $\delta(n)$ 的离散时间傅立叶变换是什么？**
*   结果是 **1**。
*   这意味着单位脉冲序列在频域上具有均匀的频谱密度，即它包含从 $-\pi$ 到 $\pi$ 的所有频率成分，且幅值相等。

**6. 序列的 DTFT 存在的条件是什么？**
*   序列必须满足**绝对可和**条件，即：
    $$\sum_{n=-\infty}^{\infty} |x(n)| < \infty$$
*   只有满足这个条件，正变换公式中的无穷级数才会收敛到一个有限值。

**7. $x(n)=a^n u(n)$，这个序列的离散时间傅立叶变换一定存在吗？**
*   **不一定。**
*   仅当 **$|a| < 1$** 时，该变换才存在。
*   如果 $|a| \ge 1$，序列随 $n$ 趋于无穷大时不衰减（发散或恒定），不满足绝对可和条件，因此变换不存在。

**8. 离散傅立叶变换是否具有周期性？周期是多少？**
*   **是**，具有周期性。
*   周期为 **$2\pi$**。
*   这是因为复指数函数 $e^{-j\omega n}$ 对 $\omega$ 具有 $2\pi$ 的周期性（即 $e^{-j(\omega+2\pi)n} = e^{-j\omega n}$，其中 $n$ 为整数）。

**9. 请简答离散傅立叶变换的共轭对称性。**
![[Pasted image 20260110204840.png]]
*   如果 $x(n)$ 是**实数序列**，其频谱 $X(e^{j\omega})$ 满足共轭对称性：
    $$X(e^{j\omega}) = X^*(e^{-j\omega})$$
*   这意味着：
    1.  频谱的**幅度** $|X(e^{j\omega})|$ 是**偶函数**（关于纵轴对称）。
    2.  频谱的**相位** $\angle X(e^{j\omega})$ 是**奇函数**（关于原点对称）。

**10. 请简述离散傅立叶变换的时移定理和频移定理。从这两个定理可以推出什么结论吗？**
*   **时移定理：** 信号在时域延迟 $n_0$ ($x(n-n_0)$)，对应频域乘以线性相位因子 $e^{-j\omega n_0}$。即幅值不变，相位发生线性变化。
*   **频移定理：** 信号在时域乘以复指数 $e^{j\omega_0 n}$，对应频谱在频域平移 $\omega_0$ ($X(e^{j(\omega-\omega_0)})$)。
*   **结论：** 一个域中的**平移**（移位），对应另一个域中的**调制**（乘以复指数函数）。

**11. 请简述离散傅立叶变换的卷积定理。**
*   **时域卷积等于频域相乘。**
*   即：若 $y(n) = x(n) * h(n)$，则 $Y(e^{j\omega}) = X(e^{j\omega}) \cdot H(e^{j\omega})$。
*   这表明线性时不变系统的输出频谱，等于输入信号的频谱与系统频率响应的乘积。

**12. 证明：当 $x(n)$ 是实序列时，$X(e^{j\omega})=X^*(e^{-j\omega})$**
*   **证明过程：**
    1.  根据定义：$X(e^{j\omega}) = \sum_{n=-\infty}^{\infty} x(n)e^{-j\omega n}$
    2.  对上式两边取共轭：
        $$X^*(e^{j\omega}) = \left[ \sum_{n=-\infty}^{\infty} x(n)e^{-j\omega n} \right]^* = \sum_{n=-\infty}^{\infty} x^*(n) (e^{-j\omega n})^*$$
    3.  因为 $x(n)$ 是实序列，所以 $x^*(n) = x(n)$。
    4.  利用复指数共轭性质 $(e^{-j\omega n})^* = e^{j\omega n} = e^{-j(-\omega)n}$。
    5.  代入得：
        $$X^*(e^{j\omega}) = \sum_{n=-\infty}^{\infty} x(n) e^{-j(-\omega)n}$$
    6.  上式右边正是 $X(e^{j(-\omega)})$ 的定义。
    7.  所以 $X^*(e^{j\omega}) = X(e^{-j\omega})$，即 $X(e^{j\omega}) = X^*(e^{-j\omega})$。得证。

		首先对 $\frac{X(z)}{z}$ 进行展开：
$$\frac{X(z)}{z} = \frac{z}{(4-z)(z-\frac{1}{4})} = \frac{A_1}{4-z} + \frac{A_2}{z-\frac{1}{4}}$$

		计算系数 $A_1$ 和 $A_2$：
$$A_1 = \left[ (4-z) \frac{X(z)}{z} \right]_{z=4} = \frac{4}{4-\frac{1}{4}} = \frac{4}{\frac{15}{4}} = \frac{16}{15}$$
$$A_2 = \left[ (z-\frac{1}{4}) \frac{X(z)}{z} \right]_{z=\frac{1}{4}} = \frac{\frac{1}{4}}{4-\frac{1}{4}} = \frac{\frac{1}{4}}{\frac{15}{4}} = \frac{1}{15}$$

		由此得到 $X(z)$ 的表达式：
$$\frac{X(z)}{z} = \frac{16/15}{4-z} + \frac{1/15}{z-\frac{1}{4}}$$
$$\therefore X(z) = \frac{16}{15} \frac{z}{4-z} + \frac{1}{15} \frac{z}{z-\frac{1}{4}} = \frac{1}{15} \left( \frac{16z}{4-z} + \frac{z}{z-\frac{1}{4}} \right)$$

	2. 长除法计算
		 (1) 左边序列部分（针对极点 $z=4$，在 $|z|<4$ 区域展开）
		计算 $\frac{16z}{4-z}$：
$$
\begin{array}{r}
4z + z^2 + \frac{1}{4}z^3 + \frac{1}{16}z^4 + \dots \\
4-z \enclose{longdiv}{16z} \\
\underline{16z - 4z^2} \\
4z^2 \\
\underline{4z^2 - z^3} \\
z^3 \\
\underline{z^3 - \frac{1}{4}z^4} \\
\frac{1}{4}z^4 \\
\underline{\frac{1}{4}z^4 - \frac{1}{16}z^5} \\
\frac{1}{16}z^5 \\
\vdots
\end{array}
$$
		展开式为：$4z + z^2 + \frac{1}{4}z^3 + \frac{1}{16}z^4 + \dots$

		(2) 因果序列部分（针对极点 $z=1/4$，在 $|z|>1/4$ 区域展开）
		计算 $\frac{z}{z-\frac{1}{4}}$：
$$
\begin{array}{r}
1 + \frac{1}{4}z^{-1} + \frac{1}{16}z^{-2} + \frac{1}{64}z^{-3} + \dots \\
z - \frac{1}{4} \enclose{longdiv}{z} \\
\underline{z - \frac{1}{4}} \\
\frac{1}{4} \\
\underline{\frac{1}{4} - \frac{1}{16}z^{-1}} \\
\frac{1}{16}z^{-1} \\
\underline{\frac{1}{16}z^{-1} - \frac{1}{64}z^{-2}} \\
\frac{1}{64}z^{-2} \\
\underline{\frac{1}{64}z^{-2} - \frac{1}{256}z^{-3}} \\
\frac{1}{256}z^{-3} \\
\vdots
\end{array}
$$
		展开式为：$1 + \frac{1}{4}z^{-1} + \frac{1}{16}z^{-2} + \frac{1}{64}z^{-3} + \dots$


**8. 设 $X(z) = \frac{3z^{-1}}{(1-3z^{-1})^2}, |z|>3$，求 $x(n)$。**
*   **分析：**
    收敛域 $|z|>3$ 表明 $x(n)$ 是**因果序列**（右边序列）。
*   **解法（长除法）：**
    将分子 $3z$ 除以分母 $z^2 - 6z + 9$：

$$
\begin{array}{r}
3z^{-1} + 18z^{-2} + 81z^{-3} + \dots \\
z^2 - 6z + 9 \enclose{longdiv}{3z \hspace{10em}} \\
\underline{3z - 18 + 27z^{-1} \hspace{4.5em}} \\
18 - 27z^{-1} \hspace{4.5em} \\
\underline{18 - 108z^{-1} + 162z^{-2} \hspace{1.5em}} \\
81z^{-1} - 162z^{-2} \hspace{1.5em} \\
\underline{81z^{-1} - 486z^{-2} + 729z^{-3}} \\
\dots \hspace{2em}
\end{array}
$$

	通过长除法，得到 $X(z)$ 的幂级数展开式：
$$X(z) = 3z^{-1} + 18z^{-2} + 81z^{-3} + \dots$$

	根据 Z 变换的定义 $X(z) = \sum_{n=-\infty}^{\infty} x(n) z^{-n}$，对比系数可得序列 $x(n)$ 的前几项：
*   $x(0) = 0$
*   $x(1) = 3$
*   $x(2) = 18$
*   $x(3) = 81$
*   ...

	*(注：此题也可以利用常用变换对公式 $n a^n u(n) \leftrightarrow \frac{az^{-1}}{(1-az^{-1})^2}$ 直接得出结果为 $x(n) = n \cdot 3^n u(n)$。)

### 第五部分 离散时间系统的时域分析

**1. 写出离散时间系统累加器的输入输出关系公式，并说明累加器的功能。**
*   **输入-输出关系定义式：**
    $$y[n] = \sum_{\ell=-\infty}^{n} x[\ell]$$
*   **功能：**
    将当前时刻以及当前时刻之前的所有输入样本进行累加。这可视作连续时间积分器的离散时间等效。

**2. 写出累加器输入输出关系的两种变形。**
*   **变形一（分离初始状态与当前输入）：**
    $$y[n] = \sum_{\ell=-\infty}^{-1} x[\ell] + \sum_{\ell=0}^{n} x[\ell] = y[-1] + \sum_{\ell=0}^{n} x[\ell], \quad n \ge 0$$
*   **变形二（递归形式）：**
    $$y[n] = \sum_{\ell=-\infty}^{n-1} x[\ell] + x[n] = y[n-1] + x[n]$$

**3. 滑动平均滤波器的功能是什么？**
*   **公式：**
    $$y[n] = \frac{1}{M} \sum_{\ell=0}^{M-1} x[n-\ell]$$
*   **功能：**
    用于平滑数据中的随机变化（去噪）。

**4. 线性内插器的功能是什么？**
*   **功能：**
    用于估计离散时间序列中相邻的一对样本值之间的样本值大小。
*   **实现步骤：**
    首先将待内插的输入序列 $x[n]$ 通过上抽样器得到 $x_u[n]$：
    $$x_u[n] = \begin{cases} x[n/L], & n=0, \pm L, \pm 2L, \dots \\ 0, & \text{otherwise} \end{cases}$$

**5. 中值滤波和均值滤波的功能和区别是什么？**
*   **功能：** 两者主要功能都是去噪。
*   **区别：**
    *   **中值滤波：** 是在一个长度为奇数的滑动窗口中取**中值**作为输出。它对于去除脉冲噪声（如椒盐噪声）且保持边缘特性效果较好。
    *   **均值滤波：** 是在一个滑动窗口中取**均值**作为输出。它对信号进行平滑处理，但可能会模糊边缘。

**6. 判断题：零输入导致零输出的系统是线性系统。**
*   **错。**
    *   **解释：** “零输入产生零输出”只是线性系统的一个必要条件，而非充分条件。一个系统可能满足零输入零输出，但不满足可加性或齐次性（例如 $y(n) = x^2(n)$，输入为0输出为0，但它是非线性的）。

**7. 验证下面的系统是否为线性系统：$y(n)=4x(n)+6$**
*   **结论：** 该系统**不是**线性系统。
*   **验证方法一（可加性分析）：**
    *   设 $x_1(n)=3$，则 $y_1(n) = 4 \times 3 + 6 = 18$
    *   设 $x_2(n)=4$，则 $y_2(n) = 4 \times 4 + 6 = 22$
    *   两者之和：$y_1(n) + y_2(n) = 18 + 22 = 40$
    *   设 $x_3(n) = x_1(n) + x_2(n) = 7$，则系统输出 $y_3(n) = 4 \times 7 + 6 = 34$
    *   因为 $y_3(n) \neq y_1(n) + y_2(n)$ ($34 \neq 40$)，不满足可加性。
*   **验证方法二（零输入零输出特性）：**
    *   当 $x(n)=0$ 时，输出 $y(n) = 4 \times 0 + 6 = 6 \neq 0$。
    *   不满足线性系统的“零输入产生零输出”特性。

**8. 验证累加器系统$y(n)=\sum_{m=-\infty}^{n}{x(m)}$是否具有时不变性。**
*   **结论：** 该系统是**移不变（时不变）系统**。
*   **验证过程：**
    1.  **先移位后变换：** 设输入为 $x(n-k)$，系统输出为
        $$T[x(n-k)] = \sum_{m=-\infty}^{n} x(m-k)$$
        令 $m' = m-k$，则
        $$= \sum_{m'=-\infty}^{n-k} x(m')$$
    2.  **先变换后移位：** 原输出 $y(n) = \sum_{m=-\infty}^{n} x(m)$，将其延迟 $k$ 得到
        $$y(n-k) = \sum_{m=-\infty}^{n-k} x(m)$$
    3.  **比较：** $y(n-k)$ 与 $T[x(n-k)]$ 表达式相同。

**9. 验证 $y(n) = \sum_{m=0}^{n} x(m)$ 系统的时不变性。**
*   **结论：** 该系统**不是**移不变系统。
*   **验证过程：**
    1.  **先移位后变换：** 输入 $x(n-k)$，输出为
        $$T[x(n-k)] = \sum_{m=0}^{n} x(m-k)$$
        令 $m' = m-k$，上限变为 $n-k$，下限变为 $-k$，即
        $$= \sum_{m'=-k}^{n-k} x(m')$$
    2.  **先变换后移位：**
        $$y(n-k) = \sum_{m=0}^{n-k} x(m)$$
    3.  **比较：** 求和下限不同（一个是 $-k$，一个是 $0$），两者不相等。

**10. 因果系统的定义是什么？线性时不变系统是因果系统的充要条件是什么？**
*   **因果系统定义：** 某时刻的输出只取决于此时刻和此时刻以前的输入的系统。即：$n=n_0$ 时的输出 $y(n_0)$ 只取决于 $n \le n_0$ 的输入 $x(n)|_{n \le n_0}$。
*   **LSI系统因果性的充要条件：** 单位脉冲响应 $h(n)$ 满足：
    $$h(n) = 0, \quad n < 0$$

**11. 稳定系统的定义、线性时不变系统是稳定系统的充要条件是什么？**
*   **稳定系统定义（BIBO）：** 有界输入产生有界输出的系统。即：如果 $|x(n)| \le M < \infty$，则有 $|y(n)| \le P < \infty$。
*   **LSI系统稳定性的充要条件：** 单位抽样响应绝对可和。
    $$\sum_{n=-\infty}^{\infty} |h(n)| = q < \infty$$

**12. 验证系统 $y(n)=nx(n)$ 的移不变特性。**
*   **结论：** 该系统**不是**移不变系统。
*   **验证方法（概念法）：**
    *   系统对移位输入的响应：$T[x(n-k)] = n \cdot x(n-k)$
    *   系统输出的移位：$y(n-k) = (n-k) \cdot x(n-k)$
    *   显然 $n \cdot x(n-k) \neq (n-k) \cdot x(n-k)$，两者不同。

**13. 什么叫 LSI 系统？**
*   同时具有**线性 (Linear)** 和**移不变性 (Shift-Invariant)** 的离散时间系统称为 LSI 系统。

**14. 什么是单位脉冲响应？**
*   输入为单位脉冲序列 $\delta(n)$ 时，系统对应的输出。通常用 $h(n)$ 表示。

**15. 判断题：任何一个系统的输出 y(n) 都可以用输入 x(n) 与单位抽样响应 h(n) 的卷积来表示。**
*   **错。**
    *   **解释：** 只有 **LSI（线性移不变）系统** 才可以。

**16. 判断下面的系统是否为因果系统。**
1.  $y(n)=nx(n)$：**是**。（输出仅取决于当前输入 $x(n)$）
2.  $y(n)=x(n+2)+ax(n)$：**不是**。（输出取决于将来时刻 $n+2$ 的输入）
3.  $y(n)=x(n^3)$：**不是**。（例如 $n=-2$ 时，取决于 $x(-8)$，是过去；但若 $n=2$ 时，取决于 $x(8)$，是将来。对于一般定义，只要存在反例即非因果）。
4.  $y(n)=x(-n)$：**不是**。（例如 $n=-1$ 时，取决于 $x(1)$，即将来输入）。
5.  $y(n)=x(n)\sin(n+2)$：**是**。（输出仅取决于当前输入 $x(n)$，$\sin(n+2)$ 只是一个随时间变化的系数）。

**17. 验证系统 $y(n)=nx(n)$ 的稳定性。**
*   **结论：** 系统**不稳定**。
*   **验证（反证法）：**
    *   取有界输入 $x(n) = 1$（单位阶跃或常数，始终有限）。
    *   输出为 $y(n) = n \times 1 = n$。
    *   当 $n \to \infty$ 时，$y(n) \to \infty$。
    *   有界输入产生了无界输出，故系统不稳定。

**18. 一个 LSI 系统的 $h(n)=a^n u(n)$，讨论其因果性和稳定性。**
*   **因果性：**
    *   因为 $u(n)$ 在 $n<0$ 时为 0，所以 $h(n) = 0$ 当 $n < 0$。
    *   符合因果系统的充要条件，所以该系统为**因果系统**。
*   **稳定性：**
    *   计算 $h(n)$ 的绝对和：
        $$\sum_{n=-\infty}^{\infty} |h(n)| = \sum_{n=0}^{\infty} |a|^n$$
    *   这是一个等比级数求和。
    *   当 **$|a| < 1$** 时，求和结果为 $\frac{1}{1-|a|} < \infty$，系统**稳定**。
    *   当 **$|a| \ge 1$** 时，求和结果趋于 $\infty$，系统**不稳定**。

### 第六部分 离散时间系统的Z域分析

**1. 写成两种系统传递函数（系统函数）的表达式。**
*   **定义式一（基于单位脉冲响应）：**
    $$H(z) = \sum_{n=-\infty}^{\infty} h[n]z^{-n}$$
*   **定义式二（基于输入输出 Z 变换之比）：**
    $$H(z) = \frac{Y(z)}{X(z)}$$

**2. 什么是 FIR 数字滤波器，什么叫 IIR 数字滤波器？**
*   **IIR (Infinite Impulse Response) 系统：** 若系统的单位冲激响应 $h(n)$ 为无限长序列，称 IIR 系统。
*   **FIR (Finite Impulse Response) 系统：** 若系统的单位冲激响应 $h(n)$ 为有限长序列，称 FIR 系统。

**3. 写出 IIR 数字滤波器系统函数归一化的标准式。**
*   $$H(z) = \frac{\sum_{m=0}^{M} b_m z^{-m}}{1 - \sum_{k=1}^{N} a_k z^{-k}}$$

**4. FIR 和 IIR 数字滤波器在差分方程上有何不同？**
*   **FIR 数字滤波器：** 输出只与当前和过去的输入 $x(n-m)$ 有关，没有反馈回路。
    $$y[n] = \sum_{k=N_1}^{N_2} h[k]x[n-k], \quad (N_1 < N_2)$$
*   **IIR 数字滤波器：** 输出不仅与输入 $x(n-m)$ 有关，还与以前的输出 $y(n-k)$ 有关（存在递归/反馈）。
    $$\sum_{k=0}^{N} d_k y[n-k] = \sum_{k=0}^{M} p_k x[n-k]$$

**5. 简述 FIR 和 IIR 数字滤波器的归一化系统函数的区别。**
*   **FIR：** 系统函数是分母为 1 的有理分式，因此在有限 $z$ 平面上没有极点（极点均在 $z=0$ 处），只有零点。
    $$H(z) = \sum_{m=0}^{M} b_m z^{-m}$$
    *   其中系数 $b_m$ 极为单位脉冲响应 $h(n)$。
    *   当 $N_1 \ge 0$ 时（因果 FIR），所有极点均在 Z 平面的原点处。收敛域为除了 $z=0$ 之外的整个 Z 平面。
*   **IIR：** 系统函数是两个多项式的比值，既有零点也有极点。

**6. M 点滑动平均滤波器是 FIR 滤波器还是 IIR 滤波器？**
*   是 **FIR 滤波器**。
*   **理由：** 其单位脉冲响应 $h[n]$ 仅在 $0 \le n \le M-1$ 区间内有值（值为 $1/M$），其余为 0，属于有限长序列。
*   **传递函数：**
    $$H(z) = \frac{1}{M} \sum_{n=0}^{M-1} z^{-n} = \frac{1}{M} \frac{1-z^{-M}}{1-z^{-1}}$$

**7. 线性时不变系统滤波器如果是稳定系统，简述其收敛域的特点。**
*   对于稳定的系统，其收敛域（ROC）必须**包含单位圆**（即 $|z|=1$）。
*   因此，在用 z 平面的零、极点图来描述 $H(z)$ 时，通常都画出单位圆，以便看清极点位置与单位圆的关系，从而判断系统稳定与否。

**8. 判断并给出依据：**
1.  **FIR 数字滤波器一定是个稳定的系统。**
    *   **答：对。**
    *   **依据：** 因为 FIR 数字滤波器其单位脉冲响应 $h(n)$ 是个有限长序列。有限长序列的 z 变换收敛域是整个 z 平面（可能除去 $z=0$ 或 $z=\infty$），肯定包含单位圆。因此，FIR 数字滤波器一定是一个稳定的系统。
2.  **FIR 数字滤波器不存在输出到输入的反馈，即 n 时刻的输出 y(n) 与 n 时刻之前的输出无关，只跟输入有关。**
    *   **答：对。**
    *   **依据：** FIR 系统的差分方程形式决定了其输出仅由当前和过去的输入加权和组成，不包含 $y(n-k)$ 项。

**9. 请简述因果系统其收敛域的形状。**
*   其收敛域在一个收敛半径之外，即：
    $$R_{h-} < |z| \le \infty$$
*   即收敛域为某圆的**外部**。

**10. 如何从系统函数的收敛域来判断一个系统的因果稳定性？**
*   **因果稳定系统**的系统函数 $H(z)$ 的**全部极点必在单位圆以内**。

**12. 设系统由下列差分方程描述：$y(n) = \frac{3}{2}y(n-1) + y(n-2) + x(n-1)$**

**(1) 求系统的系统函数 $H(z)$，并画出零极点分布图。**

*   因果系统的收敛域在最外层极点之外。

**(3) 限定系统是稳定性的，写出 $H(z)$ 的收敛域。**
*   稳定系统的收敛域必须包含单位圆（$|z|=1$），且收敛域通常为环状区域（在两个极点之间）。
*   收敛域：$0.5 < |z| < 2$（即 $|-0.5| < |z| < |2|$）

### 第七部分 离散时间系统的频域分析

**1. 一个系统的频率响应与单位脉冲响应的关系式是什么？**
*   系统的频率响应是单位抽样响应 $h(n)$ 的离散时间傅立叶变换 (DTFT)：
    $$H(e^{j\omega}) = \sum_{n=-\infty}^{\infty} h(n) \cdot e^{-j\omega n}$$

**2. 一个系统的频率响应存在的条件是什么？**
*   单位脉冲响应 $h(n)$ 必须满足**绝对可和**条件：
    $$\sum_{n=-\infty}^{\infty} |h(n)| < \infty$$

**3. 简述频率响应 $H(e^{j\omega})$ 与系统函数 $H(z)$ 的关系。**
*   频率响应是系统函数的特例，它是系统函数在 z 平面**单位圆**上的取值。即：
    $$H(e^{j\omega}) = H(z) \Big|_{z=e^{j\omega}}$$

**4. 在 Matlab 中，用于求系统频率响应的函数是哪一个？**
*   `freqz` 函数可用来求一个离散系统的频率响应。

**5. 什么是幅频响应和相频响应？**
*   系统的频率响应 $H(e^{j\omega})$ 是一个复数函数，可表示为：
    $$H(e^{j\omega}) = |H(e^{j\omega})| e^{j\phi(\omega)}$$
*   **幅频响应：** $|H(e^{j\omega})|$，描述系统的增益随信号频率的变化。
*   **相频响应：** $\phi(\omega)$，描述系统的相移随信号频率的变化。

**6. 单位脉冲响应 $h(n)$ 为实数时，其幅频响应和相频响应有什么特点？**
*   对于输入和输出都是实信号的滤波器，其频率响应具有**共轭对称性**：
    $$H(e^{j\omega}) = H^*(e^{-j\omega})$$
*   这意味着：
    *   **幅频响应**是偶函数：$|H(e^{j\omega})| = |H(e^{-j\omega})|$
    *   **相频响应**是奇函数：$\phi(\omega) = -\phi(-\omega)$

**7. 为什么一般频率响应的频率范围只画出 $0 \sim \pi$？**
*   因为 DTFT 具有周期性，周期为 $2\pi$。
*   且当 $h(n)$ 为实数时，其幅频响应具有**偶对称性**。
*   因此只需要画出一半（即 $0 \sim \pi$）即可包含所有幅度信息。

**8. 简述幅度响应的谷点和峰点的位置与零点和极点的位置关系。**
*   **零点与谷点：** 单位圆附近的零点对幅度响应的谷点的位置与深度有明显影响。当零点正好位于单位圆上时，该频率处的幅度响应为零（形成零陷）。
*   **极点与峰点：** 单位圆附近的极点对幅度响应的峰点位置和高度有明显影响。极点越靠近单位圆，该频率处的幅值增益越大。若极点在单位圆外，系统不稳定。

**9. 原点处的零极点对系统的幅频响应是否有影响？**
*   原点处的零点或极点（即 $z=0$），它到单位圆上任意一点的距离恒为 1。
*   因此，原点处的零、极点**不影响幅频响应** $|H(e^{j\omega})|$，但是会影响**相频响应**。

**10. 填空：关于滤波器设计的零极点配置。**
*   若使设计的滤波器拒绝某个频率（不让该频率信号通过），应在单位圆上相应的频率处设置一个__**零点**__ 。
*   若使设计的滤波器突出某个频率（使该频率信号尽量无衰减的通过），应在单位圆内相应的频率处设置一个__**极点**__ 。
*  __**极点**__ 越接近单位圆，在该频率处的幅频响应幅值越大。

### 第八部分 离散傅里叶变换的概念和性质

**1. 写出离散傅里叶变换DFT正变换和反变换的公式，并说出其分别表示的含义。**
*   **正变换公式：**
    $$X(k) = DFT[x(n)] = \sum_{n=0}^{N-1} x(n)W_N^{nk}, \quad 0 \le k \le N-1$$
*   **反变换公式：**
    $$x(n) = IDFT[X(k)] = \frac{1}{N} \sum_{k=0}^{N-1} X(k)W_N^{-nk}, \quad 0 \le n \le N-1$$
*   **含义：**
    离散傅里叶逆变换把 $N$ 个信号样点数据表示成了 $N$ 个旋转向量样点数据（每个旋转向量 $N$ 个样点）的加权和，构成了一个 $N$ 元一次方程组（$N$ 个权值是未知数）。离散傅里叶变换得到的 $N$ 个值就是这个 $N$ 元一次方程组的解。

**2. 傅里叶变换的四种形式是哪些？**
*   **连续时间傅里叶变换 (FT)：** 连续时间、连续频率。
*   **傅里叶级数 (FS)：** 连续时间、离散频率。
*   **序列的傅里叶变换 (DTFT)：** 离散时间、连续频率。
*   **离散傅里叶变换 (DFT)：** 离散时间、离散频率。
![[Pasted image 20260111025203.png]]

**3. Z 变换、离散时间傅里叶变换 DTFT、离散傅里叶变换 DFT 的关系是什么？**
*   **DFT 与 Z 变换的关系：**
    $$X(k) = X(z)\Big|_{z=e^{j\frac{2\pi}{N}k}}, \quad 0 \le k \le N-1$$
    即：序列 $x(n)$ 的 $N$ 点 DFT 是 $x(n)$ 的 Z 变换在单位圆上的 $N$ 点等间隔采样。
*   **DFT 与 DTFT 的关系：**
    $$X(k) = X(e^{j\omega})\Big|_{\omega=\frac{2\pi}{N}k}, \quad 0 \le k \le N-1$$
    即：序列 $x(n)$ 的 $N$ 点 DFT 是 $x(n)$ 的 DTFT 在 $[0, 2\pi]$ 上的 $N$ 点等间隔采样。

**4. 某序列的频谱 $X(e^{j\omega}) = \frac{1}{1-0.5e^{-j\omega}}$，该序列的 6 点 DFT 中的 X[0] 和 X[3] 分别等于什么？**
*   **X[0]：** 对应 $\omega = 0$。
    $$X[0] = X(e^{j0}) = \frac{1}{1-0.5} = 2$$
*   **X[3]：** 对应 $\omega = \frac{2\pi}{6} \times 3 = \pi$。
    $$X[3] = X(e^{j\pi}) = \frac{1}{1-0.5(-1)} = \frac{1}{1.5} = \frac{2}{3}$$

**5. 设序列 $x[n]$ 的 N 点 DFT 为 $X(k)$，则频率序号 k 对应的数字频率 $\omega_k$ 等于什么？**
*   $$\omega_k = \frac{2\pi}{N}k$$

**6. 在采样频率为 $F_T (Hz)$ 的数字系统中，时域序列 $x[n]$ 的序号 n 代表的实际时间为多少秒？频率序号 k 对应的数字频率为多少 Hz？**
*   **实际时间：** $\frac{n}{F_T}$ 秒。
*   **实际频率：** $\frac{F_T}{N}k$ Hz。

**7. 设序列 $x[n]$ 的 6 点 DFT 为 $X[k]$，已知 $X[0]=2, X[1]=1.5-0.866j, X[2]=0.5-0.866j, X[3]=0$，则根据对称性可得到 $X[4]=\_\_\_, X[5]=\_\_\_$。**

    *   $X[5] = X^*(6-5) = X^*(1) = (1.5-0.866j)^* = 1.5+0.866j$

### 第九部分 圆周移位和圆周卷积

**1. 设两有限长序列的长度分别是 M 与 N，欲用圆周卷积计算两者的线性卷积，则圆周卷积的长度至少应取 ( B )。**
*   A. M+N
*   B. M+N-1
*   C. M+N+1
*   D. 2(M+N)

**2. 判断题：**
1.  将 DFT 用作频谱分析时，要想提高频率分辨率，可以将时间序列补零，从而增加 DFT 的点数，达到分辨相近频率分量的目的。 (**错**)
    *   *解析：补零只能增加频谱采样的密度（栅栏效应减小），改善视觉效果，但不能提高物理分辨率。物理分辨率由信号的有效记录长度决定。*
2.  对时间序列 x(n) 补若干个零后，频谱的计算分辨率提高，即频谱的采样间隔变小。 (**对**)
    *   *解析：注意区分“计算分辨率”（采样间隔 $2\pi/N$）和“物理分辨率”。补零确实让频谱点更密了。*
3.  线性移位与圆周移位的操作过程是相同的。 (**错**)
    *   *解析：线性移位是数据左右移动，空出补零；圆周移位是移出的数据从另一端补回来。*
4.  当循环卷积区间长度大于或等于线性卷积长度时，循环卷积结果等于线性卷积。 (**对**)
5.  离散傅里叶变换中的卷积运算是线性卷积。 (**错**)
    *   *解析：DFT 对应的是圆周卷积（循环卷积）。*
6.  一个信号输入到系统之后，其输出的运算过程即为线性卷积。 (**对**)
    *   *解析：物理系统的实际响应过程是线性卷积。*

**3. 什么是泄漏效应？**
*   **答案：** 泄漏是指频谱中出现了不该有的频率分量。
*   **原因：** 主要是由于时域信号的**截断**（加窗）引起的。截断导致信号在时域不再是无限长，频域上原来的冲激函数变成了窗函数的频谱（如辛克函数），主瓣能量泄漏到了旁瓣，导致原本没有频率成分的地方出现了能量。

**4. 用 DFT 进行频谱分析时，很多时候会用到补零操作。请问补零的主要作用是什么？**
*   **答案：**
    1.  **用于计算线性卷积：** 当采用 DFT 来计算线性卷积时，要使得圆周卷积可以替代线性卷积，DFT 的长度必须满足 $N \ge N_1+N_2-1$。因此需要对每一个序列补零到该长度，再进行 DFT、频域相乘、IDFT。
    2.  **改善谱的显示效果（减小栅栏效应）：** 采用 DFT 对长度为 N 的序列进行频域分析时，若希望能分析到更多的频率点（使谱线更平滑），可以通过补零增加 DFT 的点数，从而减小频域采样间隔，显示出频谱的更多细节。

**5. 用 DFT 近似分析连续信号频谱时, 泄漏效应是由 \_\_\_\_\_\_ 引起的。**
*   **答案：** 截断（或加窗）。

**6. 已知两个有限长序列 $x_1[n](0 \le n \le 35)$ 和 $x_2[n](0 \le n \le 38)$，若用圆周卷积来计算他们的线性卷积，则圆周卷积至少应取多少点？**
*   **答案：** 74 点。
*   **解析：**
    *   线性卷积的长度 $L = N_1 + N_2 - 1$。
    *   这里 $N_1 = 36$（从0到35），$N_2 = 39$（从0到38）。
    *   $L = 36 + 39 - 1 = 74$。
    *   为了使圆周卷积不产生混叠（即等于线性卷积），圆周卷积的点数 $N$ 必须满足 $N \ge L$，即 $N \ge 74$。

**7. 设 $x_1(n)$ 和 $x_2(n)$ 都是 N 点的实数序列，试用一次 N 点 DFT 运算来计算它们各自的 DFT。**
*   **方法：** 利用两序列构成一个复序列。
    1.  构造复序列：$w(n) = x_1(n) + jx_2(n)$
    2.  计算 $w(n)$ 的 DFT：$W(k) = DFT[w(n)]$
    3.  利用 DFT 的共轭对称性质分离出 $X_1(k)$ 和 $X_2(k)$：
        *   $X_1(k) = \frac{1}{2} [W(k) + W^*((N-k)_N)]$ （对应实部 DFT）
        *   $X_2(k) = \frac{1}{2j} [W(k) - W^*((N-k)_N)]$ （对应虚部 DFT）
        *   其中 $R_N(k)$ 表示模 $N$ 运算，即 $k=0$ 时 $N-k=0$。
    已知：
$$DFT[x_1(n)] = X_1(k)$$
$$DFT[x_2(n)] = X_2(k)$$

	**解：利用两序列构成一个复序列**
$$w(n) = x_1(n) + jx_2(n)$$

	则其 DFT 为：
$$W(k) = DFT[w(n)] = DFT[x_1(n) + jx_2(n)]$$
$$W(k) = DFT[x_1(n)] + jDFT[x_2(n)]$$
$$W(k) = X_1(k) + jX_2(k)$$

1. 提取 $X_1(k)$
	由 $x_1(n) = \text{Re}[w(n)]$，利用对称性质得：
$$X_1(k) = DFT[x_1(n)] = DFT\{\text{Re}[w(n)]\} = W_{ep}(k)$$
$$X_1(k) = \frac{1}{2} \left[ W((k))_N + W^*((N - k))_N \right] R_N(k)$$

 2. 提取 $X_2(k)$
	由 $x_2(n) = \text{Im}[w(n)]$，利用对称性质得：
$$X_2(k) = DFT[x_2(n)] = DFT\{\text{Im}[w(n)]\} = \frac{1}{j} W_{op}(k)$$
$$X_2(k) = \frac{1}{2j} \left[ W((k))_N - W^*((N - k))_N \right] R_N(k)$$
	**符号说明：**
	*   $W^*$: 表示 $W$ 的共轭复数。
	*   $((k))_N$: 表示对 $N$ 取模（周期延拓）。
	*   $R_N(k)$: 表示矩形窗函数。
	*   $W_{ep}(k), W_{op}(k)$: 分别表示 $W(k)$ 的圆周共轭对称分量（偶对称部分）和圆周共轭反对称分量（奇对称部分）。

**8. 如果序列 $x(n)$ 的长度是 M，对其 DTFT 频域进行 N 点采样得到 $X(k)$，只有当 \_\_\_\_\_ 时，可由频域采样 $X(k)$ 恢复原序列 $x(n)$，否则产生时域混叠现象。**
*   **答案：** $N \ge M$
*   **解析：** 这是频域采样定理。频域采样点数必须大于等于时域序列的长度，时域才不会发生混叠，从而能无失真恢复。

**9. 如何利用 DFT 计算线性卷积？**
*   **原理：** 时域的圆周卷积对应频域的乘法。当圆周卷积长度 $L$ 满足 $L \ge M+N-1$ 时，圆周卷积的结果等于线性卷积。
*   **步骤：**
    1.  确定计算点数 $L$，满足 $L \ge N_1 + N_2 - 1$。
    2.  对两个序列 $x(n)$ 和 $h(n)$ 进行补零，使其长度均达到 $L$。
    3.  分别计算两者的 DFT，得到 $X(k)$ 和 $H(k)$。
    4.  在频域相乘：$Y(k) = X(k)H(k)$。
    5.  进行 IDFT：$y(n) = IDFT[Y(k)]$。

**10. 在实时信号处理系统中，如果输入信号为长序列，系统的单位脉冲响应为短序列，可以采用什么方案可以实现实时输出？**
*   **答案：** 采用分段卷积。
*   **具体方法：** 分段卷积方法主要有**重叠相加法** (Overlap-Add) 和**重叠保留法** (Overlap-Save)。

**11. 抗混叠滤波器的作用是什么？**
*   **答案：** 为防止采样后信号发生混叠，先要通过抗混叠滤波器对信号进行滤波。
*   **解析：** 在对模拟信号进行 A/D 转换（采样）之前，必须滤除高于采样频率一半 ($f_s/2$) 的频率成分，以满足奈奎斯特采样定理。

**12. 对实信号进行谱分析，要求谱分辨率 $F \le 10 \text{Hz}$，信号最高频率 $f_c = 2.5 \text{kHz}$，试确定最小记录时间 $T_{pmin}$，最大的采样间隔 $T_{max}$，最少的采样点数 $N_{min}$。如果 $f_c$ 不变，要求谱分辨率增加一倍，最少的采样点 $N$ 和最小的记录时间是多少？**

    *   **最小记录时间 $T_{pmin}$：** 取决于分辨率 $F$。
        $$T_{pmin} \ge \frac{1}{F} = \frac{1}{10} = 0.1 \text{s}$$
    *   **最少采样点数 $N_{min}$：** 结合采样定理 ($f_s \ge 2f_c$) 和分辨率公式 ($F = f_s/N$)。
        $$N_{min} > \frac{2f_c}{F} = \frac{2 \times 2500}{10} = 500$$
    *   **最大采样间隔 $T_{max}$：** 即最小采样频率的倒数。
        $$T_{max} = \frac{T_{pmin}}{N_{min}} = \frac{0.1}{500} = 0.2 \times 10^{-3} \text{s} = 0.2 \text{ms}$$
*   **第二问（分辨率增加一倍）：**
    *   “分辨率增加一倍”意味着频率间隔 $F$ 变小一半（精度更高），即 $F' = 5 \text{Hz}$。
    *   **最小记录时间：** $T'_{pmin} = 1/F' = 1/5 = 0.2 \text{s}$。
    *   **最少采样点数：** $N'_{min} = \frac{2f_c}{F'} = \frac{2 \times 2500}{5} = 1000$。

### 第十部分 FFT与算法、FFT应用

**1. 选择题：FFT 是以下哪种傅立叶变换的方法？**
**答案：** D
**解析：** FFT (Fast Fourier Transform) 是离散傅立叶变换 (DFT) 的快速算法。

**2. 计算 N 点的 X(k) 需要 \_\_\_\_\_\_\_\_ 次复数乘法和 \_\_\_\_\_\_\_\_ 次复数加法。**
**答案：** $N^2$ ； $N(N-1)$
**解析：** 根据 DFT 的定义式 $X(k) = \sum_{n=0}^{N-1} x(n) W_N^{kn}$，每一个 $k$ 值需要 $N$ 次复乘和 $N-1$ 次复加。共有 $N$ 个 $k$ 值，因此总共需要 $N^2$ 次复乘和 $N(N-1)$ 次复加。

**3. 快速傅立叶变换的基本思想是什么？**
**答案：**
快速傅立叶变换（FFT）的基本思想是**分治法（Divide and Conquer）**。即利用旋转因子 $W_N^{kn}$ 的**对称性**、**周期性**和**可约性**，将一个大点数（$N$点）的 DFT 分解为若干个小点数（如 $N/2$ 点）的 DFT 的组合，从而将运算复杂度从 $O(N^2)$ 降低到 $O(N \log_2 N)$。

**4. DFT 正反变换公式中，$W_N^n$ 表示的具体式子是什么？ $W_N^{\frac{N}{2}}$ 的值是多少？**
**答案：**
$W_N^n = e^{-j\frac{2\pi}{N}n}$
$W_N^{\frac{N}{2}} = -1$
**解析：** $W_N^{\frac{N}{2}} = e^{-j\frac{2\pi}{N} \cdot \frac{N}{2}} = e^{-j\pi} = -1$。

**5. DIT 和 DIF 各表示什么含义，两者的基本蝶形有何区别？**
**答案：**
*   **含义：**
    *   **DIT (Decimation-In-Time)：** 按时间抽取。
    *   **DIF (Decimation-In-Frequency)：** 按频率抽取。
*   **基本蝶形的区别：**
    *   **DIT 蝶形：** 复数乘法在加减法运算**之前**进行（输入端相乘）。即先对其中一路信号乘旋转因子，再进行加减。
    *   **DIF 蝶形：** 复数乘法在加减法运算**之后**进行（输出端相乘）。即先对两路信号进行加减，再对减法的结果乘旋转因子。

**6. 请画出蝶形运算的流图，并说明一次蝶形运算所需的复数乘法和复数加法的次数。**
**答案：**
![[Pasted image 20260111041131.png]]
**DIT 基-2 蝶形流图结构：** 假设输入为 $A, B$，输出为 $X, Y$，旋转因子为 $W$。
$$X = A + B \cdot W$$
$$Y = A - B \cdot W$$
**运算次数：** 一次基-2 蝶形运算通常包含 **1 次** 复数乘法和 **2 次** 复数加法（含减法）。

**7. 基 2 -DIT（按时间抽取）FFT 算法推导过程中，用到了 $W_N^n$ 因子的哪些性质？ （ ）**
**答案：** A, C, D
**解析：** 推导过程中主要利用了以下性质：
*   **A. 可约性** ($W_N^2 = W_{N/2}$，用于将 N 点分解为 N/2 点)
*   **C. 对称性** ($W_N^{k+N/2} = -W_N^k$，用于合并蝶形运算)
*   **D. 周期性** ($W_N^{k+N} = W_N^k$，用于扩展定义域)

**8. 由按时间抽取法 FFT 的信号流图可知，当 N=256 时，共有 \_\_\_\_\_\_\_\_ 级蝶形运算；每级都由 \_\_\_\_\_\_\_\_ 个蝶形运算组成，而每个蝶形有 \_\_\_\_\_\_\_\_ 次复乘、 \_\_\_\_\_\_\_\_ 次复加，因此每级运算都需要 \_\_\_\_\_\_\_\_ 次复乘和 \_\_\_\_\_\_\_\_ 次复加。**
**答案：** 8 ； 128 ； 1 ； 2 ； 128 ； 256
**解析：**
*   级数 $M = \log_2 N = \log_2 256 = 8$。
*   每级蝶形数 $= N/2 = 128$。
*   每个蝶形 1 次复乘，2 次复加。
*   每级复乘 $= 128 \times 1 = 128$。
*   每级复加 $= 128 \times 2 = 256$。

**9. FFT 比起直接计算 DFT，速度提高多少，即直接计算 DFT 与 FFT 算法的计算量之比是多少？**
**答案：**
计算量之比约为：$\frac{2N}{\log_2 N}$ （若仅考虑复数乘法次数的比率）
**解析：**
*   DFT 复乘次数：$N^2$
*   FFT 复乘次数：$\frac{N}{2} \log_2 N$
*   比值：$\frac{N^2}{\frac{N}{2} \log_2 N} = \frac{2N}{\log_2 N}$

**10. 按时间抽取的 FFT 算法有哪些特点？**
**答案：**
1.  **输入倒位序，输出自然序：** 输入序列需要进行比特反转（Bit-Reversal）排序，而输出频域序列是自然顺序。
2.  **原位运算：** 每一级运算的结果可以存回原来的存储单元，节省内存。
3.  **蝶形运算：** 基本运算单元是蝶形运算（包含1次复乘和2次复加）。
4.  **分级结构：** $N=2^M$ 点 FFT 分为 $M$ 级，每级由 $N/2$ 个蝶形组成。
5.  **旋转因子规律：** 旋转因子的指数随级数和蝶形位置呈规律变化。

**11. DIT 和 DIF 算法都有个共同的特点：原位运算，什么叫原位运算？**
**答案：**
**原位运算（In-place Computation）**是指在运算过程中，下一级运算的输出数据可以直接存储在上一级输入数据所占用的存储单元中，而不需要额外的存储空间来保存中间结果。这意味着 $N$ 点 FFT 只需要 $N$ 个存储单元（复数）即可完成全部运算。

**13. 如何利用FFT算法快速实现IDFT?**
**答案：**
可以通过以下两种常用方法之一利用 FFT 算法计算 IDFT：
1.  **共轭法：**
    $$x(n) = \frac{1}{N} \left[ \text{FFT} \{ X^*(k) \} \right]^*$$
    即：先对频域序列 $X(k)$ 取共轭，进行 FFT 运算，再对运算结果取共轭，最后除以 $N$。
2.  **序列重排法（或直接调用法）：**
    利用公式 $x(n) = \frac{1}{N} \sum_{k=0}^{N-1} X(k) W_N^{-kn}$，将 FFT 算法中的旋转因子 $W_N^{kn}$ 替换为 $W_N^{-kn}$（即指数符号取反），最后结果除以 $N$。

**14. 试利用N=4基2频率抽取的FFT流图计算4点序列 X[m]={0, -2j, 0, 2j}的IDFT。**
**答案：**
**计算结果：** $x[n] = \{0, 1, 0, -1\}$

**解析：**
IDFT 公式为 $x[n] = \frac{1}{N} \sum_{m=0}^{N-1} X[m] W_N^{-mn}$。
对于 $N=4$，利用流图思想（或直接代入公式计算）：
*   $n=0: \frac{1}{4}(0 - 2j + 0 + 2j) = 0$
*   $n=1: \frac{1}{4}(0 \cdot 1 - 2j \cdot j + 0 \cdot (-1) + 2j \cdot (-j)) = \frac{1}{4}(2 + 2) = 1$
*   $n=2: \frac{1}{4}(0 \cdot 1 - 2j \cdot (-1) + 0 \cdot 1 + 2j \cdot (-1)) = \frac{1}{4}(2j - 2j) = 0$
*   $n=3: \frac{1}{4}(0 \cdot 1 - 2j \cdot (-j) + 0 \cdot (-1) + 2j \cdot j) = \frac{1}{4}(-2 - 2) = -1$

**15. 实数序列的FFT有没有更快捷的方法？其如何实现？**
**答案：**
有。
**实现方法：**
利用实数序列 DFT 的共轭对称性，可以将一个 $N$ 点实数序列转换为一个 $N/2$ 点复数序列来计算：
1.  将 $N$ 点实数序列 $x[n]$ 分为偶数项和奇数项。
2.  构造一个 $N/2$ 点的复数序列 $y[n] = x[2n] + j x[2n+1]$。
3.  计算 $y[n]$ 的 $N/2$ 点 FFT，得到 $Y[k]$。
4.  利用 $Y[k]$ 的对称性质和蝶形运算公式，拆分还原出原序列的频谱 $X[k]$。
这样可以将运算量减少约一半。

**16. x[n]序列和h[n]序列的长度分别是4和6，则它们（ ）点的圆周卷积结果与线性卷积的结果不一致。**
**答案：** C
**解析：**
线性卷积的长度为 $L + M - 1 = 4 + 6 - 1 = 9$。
若圆周卷积点数 $N < 9$，则会产生时域混叠，导致结果不一致。
选项中只有 C (8) 小于 9。

**17. 写出快速卷积的步骤。**
**答案：**
1.  **补零：** 将长度为 $N_1$ 的序列 $x[n]$ 和长度为 $N_2$ 的序列 $h[n]$ 均补零延长至 $L$ 点，使得 $L \ge N_1 + N_2 - 1$（通常取 $L=2^M$）。
2.  **计算 FFT：** 分别计算补零后的序列的 FFT，得到 $X(k)$ 和 $H(k)$。
3.  **频域相乘：** 计算 $Y(k) = X(k) \cdot H(k)$。
4.  **计算 IFFT：** 对 $Y(k)$ 进行 IFFT 运算，得到 $y[n]$，即为线性卷积的结果。

**18. 什么情况下，用FFT法计算线性卷积的效率比较低？**
**答案：**
当其中一个序列（通常是滤波器 $h[n]$）的长度 **非常短** 时，或者两个序列的总长度 $N$ 很小时，直接在时域进行卷积运算的计算量可能小于或接近于 FFT 算法带来的开销（计算 FFT、乘法、IFFT），此时用 FFT 法效率较低。

**19. 简述分段卷积中重叠相加法和重叠保留法的区别。**
**答案：**
*   **重叠相加法 (Overlap-Add)：** 输入序列分段时不重叠。对每段进行补零（长度需满足线性卷积无混叠要求）后与滤波器进行卷积。由于卷积后输出长度增加，相邻输出段的尾部和头部在时域上会有重叠，需要将重叠部分**相加**才能得到最终结果。
*   **重叠保留法 (Overlap-Save)：** 输入序列分段时各段之间有重叠（重叠长度为滤波器长度减 1）。对每段直接进行圆周卷积。由于圆周卷积会导致前部数据混叠（错误），因此**丢弃**每段输出的前部混叠点，**保留**后部的有效点，最后将各段的有效部分直接拼接。

**20. 重叠相加法中，设h[n]长度为3，输入序列x[n]分段后每小段的长度为5，用快速卷积求解每小段的输出序列时，需要把h[n]补零（ ）点，每小段的输入序列补零（ ）点。**
**答案：** 4 ； 2
**解析：**
线性卷积长度 $L_{conv} = 5 + 3 - 1 = 7$。
为避免混叠，圆周卷积长度至少为 7。
*   $h[n]$ 原长 3，需补零 $7-3=4$ 点。
*   $x[n]$ 小段原长 5，需补零 $7-5=2$ 点。

**21. 利用重叠保留法进行分段卷积时，输入的各小段必须重叠P个抽样点，每一段产生的输出中保留Q个抽样点，使这些从每一段得到的抽样连接在一起时，得到的序列就是所要求的滤波输出。现利用一个单位抽样响应点数N = 50 的有限冲激响应滤波器来过滤一串很长的数据。假设输入的各段长度为100个抽样点，而离散傅里叶变换的长度为128点。进一步假设，圆周卷积的输出序列标号是从 n = 0到 n = 127，则：**
**1）P和Q的值是多少？**
**2）求取出来的Q个点的起点和终点的标号，即确定从圆周卷积的128点中要取出哪些点，去和前一段的点衔接起来。**
**答案：**
**1）** $P = 49$ ； $Q = 79$
**2）** 起点标号：49 ； 终点标号：127

**解析：**
*   **1）**
    *   重叠点数 $P = \text{滤波器长度} - 1 = 50 - 1 = 49$。
    *   FFT 点数 $N_{FFT} = 128$。
    *   由于前 $P$ 点是混叠的，有效输出点数 $Q = N_{FFT} - P = 128 - 49 = 79$。
*   **2）**
    *   在重叠保留法中，圆周卷积结果的前 $M-1$ (即 49) 个点是混叠错误的，应舍去。
    *   后 $N_{FFT} - (M-1)$ 个点是正确的线性卷积结果。
    *   因此，保留的标号范围是从 $49$ 到 $127$。

**22. 写出两个序列x[n]和y[n]的线性卷积和互相关函数的公式，比较两个公式的区别。**
**答案：**
*   **线性卷积公式：**
    $$x[n] * y[n] = \sum_{m=-\infty}^{\infty} x[m] y[n-m]$$
*   **互相关函数公式：**
    $$R_{xy}[n] = \sum_{m=-\infty}^{\infty} x[m] y[m+n]$$ （或 $R_{xy}[n] = \sum_{m=-\infty}^{\infty} x[m-n] y[m]$）
*   **区别：**
    卷积运算中，其中一个序列（$y[n]$）需要先**翻转**（Time Reversal，即 $y[-m]$）再平移；而互相关运算中，序列不需要翻转，直接平移相乘累加。如果 $y[n]$ 是偶对称序列，则两者的结果相同。

### 第十一部分 IIR数字滤波器
#### 11.1 IIR 数字滤波器的设计方法

**1. 简述模拟滤波器和数字滤波器的区别。**

**答案：**
*   **处理信号类型：** 模拟滤波器处理连续时间、连续幅度的模拟信号；数字滤波器处理离散时间、量化幅度的数字信号。
*   **实现方式：** 模拟滤波器由电阻、电容、电感、运放等硬件器件组成；数字滤波器由加法器、乘法器、延时单元组成，通常通过软件（如 DSP、MCU）或专用数字硬件（FPGA）实现。
*   **性能与稳定性：** 模拟滤波器易受元器件精度、温度漂移影响；数字滤波器参数由系数决定，精度高，稳定性好，且易于修改参数（可编程）。

**2. 数字滤波器能否完全取代模拟滤波器？**

**答案：**
不能。
**解析：** 现实世界的信号（如声音、光、无线电波）本质上是模拟的。在信号进入数字系统之前，必须通过模拟滤波器（抗混叠滤波器）限制带宽以满足采样定理；在数字信号输出后，通常需要模拟滤波器（平滑/重构滤波器）滤除高频镜像分量。此外，在高频微波领域，模拟滤波器仍具有不可替代的优势。

**3. 什么是 IIR 数字滤波器？相对于 FIR 数字滤波器，IIR 数字滤波器有哪些特点？**

**答案：**
*   **定义：** IIR（Infinite Impulse Response）即无限长单位冲激响应数字滤波器。
*   **特点（相对于 FIR）：**
    1.  **结构：** 具有反馈回路（递归结构）。
    2.  **相位：** 通常具有非线性相位特性（FIR 可以严格线性相位）。
    3.  **效率：** 在满足相同幅频特性指标下，IIR 所需的阶数通常远低于 FIR，计算量小，存储资源占用少。
    4.  **稳定性：** 极点必须在单位圆内才能稳定（FIR 总是稳定的）。

**4. 简述 IIR 数字滤波器的间接设计法的步骤。**

**答案：**
1.  **确定指标：** 将给定的数字滤波器技术指标（$\omega_p, \omega_s, \alpha_p, \alpha_s$）转换为模拟滤波器的技术指标（$\Omega_p, \Omega_s$）。
2.  **模拟设计：** 根据转换后的指标，设计一个模拟低通原型滤波器 $H_a(s)$（如巴特沃斯、切比雪夫等）。
3.  **离散化：** 利用脉冲响应不变法或双线性变换法，将模拟传输函数 $H_a(s)$ 映射为数字传输函数 $H(z)$。

**5. 简述脉冲响应不变法的思想和步骤。**

**答案：**
*   **思想：** 使数字滤波器的单位脉冲响应 $h[n]$ 等于模拟滤波器单位冲激响应 $h_a(t)$ 在采样点 $t=nT$ 处的值，即 $h[n] = h_a(nT)$。
*   **步骤：**
    1.  对 $H_a(s)$ 进行部分分式展开：$H_a(s) = \sum_{k=1}^{N} \frac{A_k}{s - s_k}$。
    2.  利用变换公式将极点映射到 z 平面：$H(z) = \sum_{k=1}^{N} \frac{A_k}{1 - e^{s_k T} z^{-1}}$。

**6. 简述脉冲响应不变法的优缺点。**

**答案：**
*   **优点：** 模拟频率 $\Omega$ 和数字频率 $\omega$ 在低频段呈线性关系（$\omega = \Omega T$）；保持了冲激响应的形状。
*   **缺点：** 存在**频谱混叠**现象。数字滤波器的频响是模拟滤波器频响的周期延拓，如果模拟滤波器不是严格带限的，高频部分会混叠到低频部分，导致失真。

**7. 脉冲响应不变法可以用于哪种类型设计 IIR 数字滤波器？为什么？**

**答案：**
*   **适用类型：** 低通、带通滤波器。
*   **原因：** 脉冲响应不变法存在频谱混叠。低通和带通滤波器的幅频响应在高频段随频率增加而衰减，混叠影响较小。而高通和带阻滤波器在高频段幅值不为零，使用该方法会导致严重的频谱混叠，完全破坏滤波特性。

**8. 简述双线性变换法的思想、步骤和优缺点。**

**答案：**
*   **思想：** 利用非线性频率压缩变换，将整个模拟频率轴 $j\Omega$ ($-\infty \sim +\infty$) 压缩映射到 z 平面的单位圆上 ($-\pi \sim \pi$)，从而消除混叠。
*   **步骤：**
    1.  **预畸变：** 将数字频率指标 $\omega$ 转换为模拟频率指标 $\Omega = \frac{2}{T}\tan(\frac{\omega}{2})$。
    2.  设计模拟滤波器 $H_a(s)$。
    3.  **代入变换：** 将 $s = \frac{2}{T} \frac{1-z^{-1}}{1+z^{-1}}$ 代入 $H_a(s)$ 得到 $H(z)$。
*   **优点：** 彻底消除了频谱混叠现象。
*   **缺点：** 模拟频率与数字频率之间是非线性关系（频率翘曲），导致数字滤波器的相位特性和幅度形状（在宽频带时）发生畸变。

**9. 判断题：**

1.  用双线性变换法设计 IIR DF 时，预畸并不能消除变换中产生的所有频率点的非线性畸变。 **（正确）**
    *   *解析：预畸变只是校正了关键频率点（如截止频率），整个频率轴的非线性映射关系依然存在。*
2.  采用双线性变换法设计 IIR DF 时，如果设计出的模拟滤波器具有线性幅度响应特性，那么转换后的数字滤波器也具有线性幅度响应特性。 **（错误）**
    *   *解析：由于频率轴的非线性压缩 $\omega = 2\arctan(\frac{\Omega T}{2})$，模拟域的线性形状映射到数字域会发生弯曲。*
3.  脉冲响应不变法和双线性变换法都能够将 S 平面的左半平面映射到 z 平面的单位圆内。 **（正确）**
4.  脉冲响应不变法使模拟角频率和数字角频率建立线性关系。 **（正确）**
5.  双线性变换法使 s 平面和 z 平面建立一一映射关系。 **（正确）**

**10. 双线性变换 $s = \frac{1-z^{-1}}{1+z^{-1}}$ 将模拟角频率\_\_\_\_\_\_\_\_映射到了数字角频率 $\pi$。**

**答案：** $\infty$ （无穷大）

**11. 用双线性变换法和模拟低通滤波器来设计一个数字低通滤波器，假设模拟低通数字滤波器的截止频率 $\Omega_c = 4000\pi rad/s$，且选取双线性变换参数 $T = 0.4ms$，所得数字滤波器的截止频率 $\omega_c = (\quad)$ ？**

**答案：** $2\arctan(0.8\pi)$ （约 2.38 rad 或 $0.76\pi$）

**解析：**
根据双线性变换频率关系：$\Omega = \frac{2}{T} \tan(\frac{\omega}{2})$
则 $\omega_c = 2 \arctan(\frac{\Omega_c T}{2})$
代入数据：$\frac{\Omega_c T}{2} = \frac{4000\pi \times 0.4 \times 10^{-3}}{2} = \frac{1.6\pi}{2} = 0.8\pi$
$\omega_c = 2 \arctan(0.8\pi)$

#### 11.2 IIR 数字低通滤波器的设计

**1. 衡量数字滤波器主要有哪些技术指标？**

**答案：**
主要技术指标包括：
*   **通带截止频率 ($\omega_p$)**
*   **阻带截止频率 ($\omega_s$)**
*   **通带最大衰减/波纹 ($\alpha_p$ 或 $R_p$, 单位 dB)**
*   **阻带最小衰减 ($\alpha_s$ 或 $A_s$, 单位 dB)**

**2. 简述间接设计 IIR 数字低通滤波器的方法和步骤。**

**答案：**
1.  确定数字低通滤波器的技术指标 ($\omega_p, \omega_s, \alpha_p, \alpha_s$)。
2.  选择转换方法（脉冲响应不变法或双线性变换法），将数字指标转换为模拟低通滤波器的指标 ($\Omega_p, \Omega_s$)。如果是双线性变换法，需使用预畸变公式。
3.  根据模拟指标计算滤波器阶数 $N$ 和 3dB 截止频率 $\Omega_c$。
4.  设计归一化模拟低通原型滤波器，并去归一化得到 $H_a(s)$。
5.  利用选定的变换公式将 $H_a(s)$ 转换为 $H(z)$。

**3. 简述巴特沃斯、切比雪夫、椭圆等原型模拟滤波器的幅频特性。**

**答案：**
*   **巴特沃斯 (Butterworth)：** 通带和阻带内幅频特性都是平坦的（单调下降），没有波纹，被称为“最大平坦滤波器”。
*   **切比雪夫 (Chebyshev)：**
    *   I 型：通带内有等波纹，阻带内单调下降。
    *   II 型：通带内平坦，阻带内有等波纹。
    *   特点：在相同阶数下，过渡带比巴特沃斯更陡峭。
*   **椭圆 (Elliptic)：** 通带和阻带内均有等波纹。在相同指标下，所需的阶数最低，过渡带最陡峭。

**4. 简述低通巴特沃斯模拟滤波器的设计步骤。**

**答案：**
1.  根据通带衰减 $\alpha_p$、阻带衰减 $\alpha_s$ 和频率比 $\lambda = \Omega_s / \Omega_p$ 计算滤波器阶数 $N$。
2.  计算 3dB 截止频率 $\Omega_c$。
3.  确定 $s$ 平面左半平面的 $N$ 个极点位置（均匀分布在半径为 $\Omega_c$ 的圆周上）。
4.  利用极点构造系统函数 $H(s) = \frac{\Omega_c^N}{\prod_{k=1}^N (s - s_k)}$。

**5. 导出三阶巴特沃斯模拟低通滤波器的传输函数，设 $\Omega_c = 1 rad/s$。**

**答案：**
$H(s) = \frac{1}{s^3 + 2s^2 + 2s + 1}$

**解析：**
1.  $N=3$，极点间隔 $180^\circ/3 = 60^\circ$。
2.  极点分布在单位圆左半平面，角度为 $180^\circ, 180^\circ \pm 60^\circ$，即 $180^\circ, 120^\circ, 240^\circ$。
3.  极点值为：
    *   $s_1 = -1$
    *   $s_{2,3} = -\cos(60^\circ) \pm j\sin(60^\circ) = -0.5 \pm j\frac{\sqrt{3}}{2}$
4.  分母多项式 $D(s) = (s - s_1)(s - s_2)(s - s_3) = (s+1)(s^2 + s + 1) = s^3 + 2s^2 + 2s + 1$。
5.  分子为 $\Omega_c^3 = 1$。

**6. $H(s) = \frac{1}{(s+2)(s+3)}$ 已知模拟低通滤波器系统函数为：采用脉冲响应不变法将其转换为 IIR 数字滤波器（T=1s）。**

**答案：**
$$H(z) = \frac{1}{1 - e^{-2}z^{-1}} - \frac{1}{1 - e^{-3}z^{-1}}$$
或者合并通分：
$$H(z) = \frac{(e^{-2} - e^{-3})z^{-1}}{1 - (e^{-2} + e^{-3})z^{-1} + e^{-5}z^{-2}}$$

**解析：**
1.  部分分式展开：$H(s) = \frac{1}{s+2} - \frac{1}{s+3}$。
2.  利用变换对 $\frac{1}{s-p_k} \to \frac{1}{1 - e^{p_k T}z^{-1}}$。
3.  代入 $T=1$，得 $H(z) = \frac{1}{1 - e^{-2}z^{-1}} - \frac{1}{1 - e^{-3}z^{-1}}$。

**7. 用双线性变换法和二阶归一化模拟低通 Butterworth 滤波器 $H_{an}(s) = \frac{1}{s^2+\sqrt{2}s+1}$，设计一个 3dB 截止频率为 2.5kHz 的数字低通滤波器，采样频率为 10kHz。**

**答案：**
$$H(z) = \frac{1}{2+\sqrt{2}} \cdot \frac{1 + 2z^{-1} + z^{-2}}{1 + \frac{2-\sqrt{2}}{2+\sqrt{2}}z^{-2}} \approx 0.2929 \frac{1 + 2z^{-1} + z^{-2}}{1 + 0.1716z^{-2}}$$

**解析：**
1.  **数字频率：** $\omega_c = 2\pi \frac{f_c}{f_s} = 2\pi \frac{2.5k}{10k} = 0.5\pi$。
2.  **预畸变（求模拟截止频率）：** $\Omega_c = \frac{2}{T} \tan(\frac{\omega_c}{2}) = \frac{2}{T} \tan(\frac{\pi}{4}) = \frac{2}{T}$。
3.  **去归一化：** 将 $H_{an}(s)$ 中的 $s$ 替换为 $s/\Omega_c$。
    $H_a(s) = H_{an}(\frac{s}{2/T})$。
4.  **双线性变换：** 令 $s = \frac{2}{T} \frac{1-z^{-1}}{1+z^{-1}}$。
    此时 $\frac{s}{\Omega_c} = \frac{\frac{2}{T} \frac{1-z^{-1}}{1+z^{-1}}}{\frac{2}{T}} = \frac{1-z^{-1}}{1+z^{-1}}$。
    代入 $H_{an}(s)$：
    $$H(z) = \frac{1}{(\frac{1-z^{-1}}{1+z^{-1}})^2 + \sqrt{2}(\frac{1-z^{-1}}{1+z^{-1}}) + 1}$$
    分子分母同乘 $(1+z^{-1})^2$ 并整理：
    $$H(z) = \frac{(1+z^{-1})^2}{(1-z^{-1})^2 + \sqrt{2}(1-z^{-2}) + (1+z^{-1})^2}$$
    $$H(z) = \frac{1 + 2z^{-1} + z^{-2}}{(2+\sqrt{2}) + (2-\sqrt{2})z^{-2}}$$

#### 11.3：IIR 数字滤波器的谱变换方法

**1. 设计数字低通滤波器，要求在通带内频率低于 $0.2\pi$ rad 时，容许幅度误差在 1dB；在频率 $0.3\pi$ 到 $\pi$ 之间的阻带误差大于 15dB。指定模拟滤波器采用 Butterworth 模拟低通滤波器。试分别用冲激响应不变法和双线性变换法设计滤波器。**

**答案：**
*(此处仅列出设计思路与关键计算式)*

**方法一：冲激响应不变法**
1.  取 $T=1$（或其他值，最终会被约掉）。
2.  **模拟指标计算：** $\Omega_p = \frac{\omega_p}{T} = 0.2\pi$, $\Omega_s = \frac{\omega_s}{T} = 0.3\pi$。
3.  **设计模拟滤波器：** 根据 $\Omega_p, \Omega_s, \alpha_p=1dB, \alpha_s=15dB$ 计算阶数 $N$ 和截止频率 $\Omega_c$。
4.  得到 $H_a(s)$ 并展开为部分分式。
5.  **变换：** $H(z) = \sum \frac{A_k}{1 - e^{s_k}z^{-1}}$。

**方法二：双线性变换法**
1.  取 $T=2$（方便计算，或任意值）。
2.  **预畸变：**
    $\Omega_p = \tan(\frac{0.2\pi}{2}) = \tan(0.1\pi) \approx 0.3249$
    $\Omega_s = \tan(\frac{0.3\pi}{2}) = \tan(0.15\pi) \approx 0.5095$
3.  **设计模拟滤波器：** 根据新的 $\Omega_p, \Omega_s$ 及 $\alpha_p, \alpha_s$ 设计 $H_a(s)$。
4.  **变换：** 将 $s = \frac{1-z^{-1}}{1+z^{-1}}$ 代入 $H_a(s)$。

**2. 如何通过模拟谱变换，采用间接设计法，设计数字高通/带通/带阻滤波器？**

**答案：**
1.  将待设计的数字高通/带通/带阻指标，通过**双线性变换**（预畸变）转换为对应的模拟高通/带通/带阻指标。
2.  通过**模拟频带变换**公式，将上述模拟指标转换为**模拟低通原型**指标。
3.  设计归一化模拟低通原型滤波器 $H_{lp}(s)$。
4.  利用模拟频带变换的逆过程，将 $H_{lp}(s)$ 转换为所需的模拟滤波器 $H_a(s)$（如 $s \to \Omega_c/s$ 变高通）。
5.  利用双线性变换法将 $H_a(s)$ 离散化为数字滤波器 $H(z)$。

**3. 如何通过数字谱变换，采用间接设计法，设计数字高通/带通/带阻滤波器？**

**答案：**
1.  设计一个具有特定截止频率的**数字低通滤波器** $H_{LP}(z)$。
2.  利用**全通变换**函数，将 $H_{LP}(z)$ 中的 $z^{-1}$ 替换为 $G(z^{-1})$。
    *   例如低通到高通变换：$z^{-1} \to -\frac{z^{-1} + \alpha}{1 + \alpha z^{-1}}$。
3.  替换后的系统函数即为所需的目标滤波器。

**4. 用 MATLAB 来设计 IIR 数字滤波器时，需要先确定哪些事项，才决定用相应的函数来实现？**

**答案：**
1.  **滤波器类型：** 低通、高通、带通还是带阻。
2.  **逼近函数类型：** 巴特沃斯 (Butterworth)、切比雪夫 (Chebyshev I/II) 还是椭圆 (Elliptic)。
3.  **设计方法：** 是基于模拟原型设计（需要 `buttord`/`butter` 加 `s` 参数再用 `bilinear`/`impinvar`），还是直接设计数字滤波器（直接用 `butter` 等）。
4.  **技术指标：** 通带/阻带截止频率、通带波纹、阻带衰减。

**5. 已知数字低通滤波器的技术指标为：通带截止 $\omega_p=2 rad$，阻带截止 $\omega_s=2.6 rad$，通带最大衰减 $\alpha_p=1dB$，阻带最小衰减 $\alpha_s=38dB$。试用脉冲响应不变法的 Matlab 设计函数实现该数字低通滤波器设计（T=1s）。**

### 第十二部分 FIR线性相位滤波器
#### 12.1 线性相位

**1. 线性相位对系统有何意义？一个FIR滤波器怎样实现线性相位的？**

**答案：**
*   **意义：** 线性相位意味着系统对所有频率成分的延迟时间（群延迟）是常数。这样信号通过系统后，各频率分量的相对相位关系保持不变，只会产生整体的时间延迟，而不会产生相位失真（波形畸变）。这对图像处理、数据传输等对波形敏感的应用至关重要。
*   **实现方法：** FIR 滤波器的单位脉冲响应 $h[n]$ 必须关于中心点满足**偶对称**或**奇对称**条件。
    *   偶对称：$h[n] = h[N-1-n]$
    *   奇对称：$h[n] = -h[N-1-n]$

**2. 四类线性相位FIR数字滤波器的幅频响应各有那些特点？即四类线性相位FIR数字滤波器分别适用于设计哪些选频特性的滤波器？**

**答案：**
*   **第一类（偶对称，N为奇数）：** 幅度函数 $H(\omega)$ 无强制零点。
    *   **适用：** 低通、高通、带通、带阻（全能型）。
*   **第二类（偶对称，N为偶数）：** 在 $\omega=\pi$ 处必有零点，即 $H(\pi)=0$。
    *   **适用：** 低通、带通。（不能用于高通和带阻）。
*   **第三类（奇对称，N为奇数）：** 在 $\omega=0$ 和 $\omega=\pi$ 处必有零点，即 $H(0)=0, H(\pi)=0$。
    *   **适用：** 带通。（不能用于低通、高通、带阻）。
*   **第四类（奇对称，N为偶数）：** 在 $\omega=0$ 处必有零点，即 $H(0)=0$。
    *   **适用：** 高通、带通。（不能用于低通和带阻）。

**3. 滤波器 $H(z)=3+5z^{-1}+2z^{-2}+2z^{-3}+5z^{-4}+3z^{-5}$，**
**（1）这是哪类线性相位FIR数字滤波器？**
**（2）该滤波器可以适用于设计哪些类型的滤波器？**
**（3）该滤波器在哪个位置必然有零点？**

**答案：**
*   **（1）** 系数为 $\{3, 5, 2, 2, 5, 3\}$，满足偶对称 $h[n]=h[N-1-n]$，且长度 $N=6$ 为偶数。因此属于**第二类**线性相位 FIR 数字滤波器。
*   **（2）** 适用于设计**低通**或**带通**滤波器。
*   **（3）** 在 $z=-1$ （即频率 $\omega=\pi$）处必然有零点。

**4. 判断题：四种FIR数字滤波器的相位特性与h(n)的值有关。**

**答案：** 错误
**解析：** 线性相位 FIR 的相位特性公式为 $\theta(\omega) = -\frac{N-1}{2}\omega + \beta$。其线性斜率仅取决于滤波器长度 $N$，截距 $\beta$ 仅取决于对称类型（偶对称或奇对称），与 $h[n]$ 的具体数值大小无关。

**5. 判断题：第三类线性相位FIR DF的h（n）共有7个样值，必有h（3）=0.**

**答案：** 正确
**解析：** 第三类为奇对称，中心点 $n = (N-1)/2 = 3$。根据奇对称性质 $h[3] = -h[7-1-3] = -h[3]$，即 $2h[3]=0$，故 $h[3]=0$。

**6. 某线性相位滤波器，N=5, h(0) = h(1) = h(3) = h(4) = -1/2, h(2) = 2，求幅度函数 H(ω)。**

**答案：**
该滤波器为第一类线性相位（偶对称，N=5）。
幅度函数公式为：$H_g(\omega) = h(\frac{N-1}{2}) + 2\sum_{n=0}^{\frac{N-3}{2}} h(n) \cos[(\frac{N-1}{2}-n)\omega]$
代入 $N=5$ 及系数：
$$H_g(\omega) = h(2) + 2h(1)\cos(\omega) + 2h(0)\cos(2\omega)$$
$$H_g(\omega) = 2 + 2(-\frac{1}{2})\cos(\omega) + 2(-\frac{1}{2})\cos(2\omega)$$
$$H_g(\omega) = 2 - \cos(\omega) - \cos(2\omega)$$

**7. 线性相位FIR DF的零点组分成哪几种情况？**

**答案：**
1.  **互为倒数的实数对：** $(z_i, z_i^{-1})$
2.  **单位圆上的共轭对：** $(e^{j\omega_k}, e^{-j\omega_k})$
3.  **互为倒数的共轭复数四元组：** $(z_k, z_k^*, z_k^{-1}, (z_k^*)^{-1})$

**8. 线性相位FIR DF的零点是2, 0.5, j, -j,该系统是第（ 1 ）类线性相位FIR DF？**

**答案：** 1
**解析：** 零点个数为 4，故阶数 $M=4$，长度 $N=5$（奇数）。零点包含互为倒数的实数对 $(2, 0.5)$ 和单位圆上的共轭对 $(j, -j)$，且没有强制的 $z=1$ 或 $z=-1$ 零点，符合第一类特征。

**9. 带阻滤波器可以用第（ ）类线性相位FIR DF来实现？**

**答案：** 1
**解析：** 带阻滤波器要求在 $\omega=0$ 和 $\omega=\pi$ 处都有非零响应。只有第一类满足此条件。

**10. 某线性相位FIR DF的h(n)前三个样值是2，-1，3，后面的样值为（ ）时，可以用来设计高通滤波器。**

**答案：** -3, 1, -2
**解析：** 题目给出前三个值，暗示 $N=6$（偶数）。要设计高通滤波器，必须在 $\omega=\pi$ 处有响应，在 $\omega=0$ 处衰减。
*   若为偶对称（第二类），$H(\pi)=0$，不能做高通。
*   若为奇对称（第四类），$H(0)=0, H(\pi) \neq 0$，适合做高通。
*   因此需构造奇对称序列：$h[n] = -h[N-1-n]$。
*   $h[3] = -h[2] = -3$
*   $h[4] = -h[1] = 1$
*   $h[5] = -h[0] = -2$

**11. 第二类线性相位FIR DF系统H(z)的其中三个零点为z=6，z=j；z=1，写出其他的零点。**

**答案：** $1/6, -j, -1$
**解析：**
*   $z=6$ 的倒数是 $1/6$。
*   $z=j$ 的共轭是 $-j$（且 $1/j = -j$）。
*   $z=1$ 的倒数是 $1$。
*   **关键：** 第二类线性相位滤波器（偶对称，偶长度）必然在 $z=-1$ 处有一个零点。
*   因此其他零点为 $1/6, -j, -1$。

#### 12.2 窗函数法设计

**1. 窗函数法设计FIR数字滤波器的思想是什么？**

**答案：**
从理想滤波器的频率响应 $H_d(e^{j\omega})$ 出发，求出其对应的无限长单位脉冲响应 $h_d[n]$，然后用一个有限长的窗函数序列 $w[n]$ 截取（相乘）$h_d[n]$，得到有限长因果序列 $h[n] = h_d[n]w[n]$，以此逼近理想特性。

**2. 加窗处理后对频率响应产生的影响是什么？**

**答案：**
加窗在时域是相乘，在频域是卷积：$H(e^{j\omega}) = \frac{1}{2\pi} H_d(e^{j\omega}) * W(e^{j\omega})$。
影响主要有两点：
1.  **过渡带变宽：** 理想滤波器的陡峭边缘被“涂抹”，过渡带宽度取决于窗函数主瓣宽度。
2.  **产生肩峰和波纹（吉布斯效应）：** 通带和阻带出现波动，阻带衰减受限，这取决于窗函数旁瓣的相对幅度。

**3. 什么是吉布斯效应？**

**答案：**
用有限项傅里叶级数（或有限长序列）逼近在不连续点具有跳变的周期函数（或理想频响）时，在不连续点附近会产生高频振荡（过冲和下冲）。增加截取长度 $N$ 只能使振荡变窄，但不能改变最大过冲的幅度（约 9%）。

**4. 用窗函数法设计FIR DF时，对窗函数的要求是什么？**

**答案：**
1.  **主瓣宽度尽可能窄：** 以获得陡峭的过渡带。
2.  **旁瓣幅度尽可能小（能量集中在主瓣）：** 以获得通带平坦和阻带高衰减。
*(注：这两者通常是矛盾的，需根据具体指标折衷选择)*

**5. 简述几种常见的窗函数的特点。**

**答案：**
*   **矩形窗：** 主瓣最窄（过渡带最窄），但旁瓣最高（-13dB），阻带衰减差。
*   **汉宁窗 (Hanning)：** 主瓣较宽，旁瓣较低（-31dB），高频衰减快。
*   **汉明窗 (Hamming)：** 主瓣宽度同汉宁，第一旁瓣更低（-41dB），但高频衰减慢。
*   **布莱克曼窗 (Blackman)：** 主瓣宽（过渡带最宽），旁瓣极低（-57dB），阻带衰减最好。

**6. 简述窗函数法设计FIR DF的设计步骤。**

**答案：**
1.  根据给定的技术指标（$\omega_p, \omega_s, \alpha_s$ 等），确定理想滤波器的类型和截止频率 $\omega_c$。
2.  根据阻带衰减指标 $\alpha_s$，选择合适的窗函数类型 $w[n]$。
3.  根据过渡带宽度 $\Delta\omega = |\omega_s - \omega_p|$，估算所需的滤波器长度 $N$。
4.  计算理想脉冲响应 $h_d[n]$（通常利用 $\alpha = (N-1)/2$ 进行移位使其因果）。
5.  计算实际脉冲响应 $h[n] = h_d[n] w[n]$。
6.  验算性能指标。

**7. 设计一个线性相位FIR低通滤波器，给定抽样频率为 $\Omega_s=2\pi\times1.5\times10^4(rad/sec)$，通带截止频率为 $\Omega_p=2\pi\times1.5\times10^3(rad/sec)$，阻带截止频率为 $\Omega_{st}=2\pi\times3\times10^3(rad/sec)$，阻带衰减不小于-50dB。请采用窗函数法设计一个FIR DF.**

**答案：**
1.  **计算数字频率：**
    *   采样频率 $F_s = 1.5 \times 10^4 = 15000$ Hz。
    *   $\omega_p = \frac{\Omega_p}{F_s} = \frac{2\pi \times 1500}{15000} = 0.2\pi$。
    *   $\omega_{st} = \frac{\Omega_{st}}{F_s} = \frac{2\pi \times 3000}{15000} = 0.4\pi$。
2.  **确定参数：**
    *   截止频率 $\omega_c = \frac{0.2\pi + 0.4\pi}{2} = 0.3\pi$。
    *   过渡带宽度 $\Delta\omega = 0.4\pi - 0.2\pi = 0.2\pi$。
3.  **选择窗函数：**
    *   要求阻带衰减 $\ge 50dB$。汉明窗约 41dB（不足），布莱克曼窗约 57dB（满足）。选用 **布莱克曼窗 (Blackman)**。
4.  **确定长度 N：**
    *   布莱克曼窗过渡带近似公式：$\Delta\omega \approx \frac{11\pi}{N}$ (或 $5.5 \times \frac{2\pi}{N}$)。
    *   $N \ge \frac{11\pi}{0.2\pi} = 55$。取奇数 $N=55$ 或 $57$ 以保证第一类线性相位。设 $N=55$。
    *   中心对称点 $\tau = \frac{N-1}{2} = 27$。
5.  **求 $h[n]$：**
    $$h_d[n] = \frac{\sin[0.3\pi(n-27)]}{\pi(n-27)}$$
    $$w[n] = 0.42 - 0.5\cos(\frac{2\pi n}{54}) + 0.08\cos(\frac{4\pi n}{54}), \quad 0 \le n \le 54$$
    $$h[n] = h_d[n] \cdot w[n]$$

**8. 用窗函数法设计线性相位FIR低通滤波器，设N=11，$\omega_c=0.5\pi$ rad。**

**答案：**
1.  **确定中心点：** $\tau = \frac{N-1}{2} = \frac{10}{2} = 5$。
2.  **理想脉冲响应：**
    $$h_d[n] = \frac{\sin[0.5\pi(n-5)]}{\pi(n-5)}$$
    特例：当 $n=5$ 时，利用洛必达法则，$h_d[5] = 0.5$。
3.  **加窗（假设为矩形窗，题目未指定）：**
    $$h[n] = h_d[n], \quad 0 \le n \le 10$$
    计算各点值（利用对称性 $h[n]=h[10-n]$）：
    *   $h[5] = 0.5$
    *   $h[4] = h[6] = \frac{\sin(-0.5\pi)}{-\pi} = \frac{-1}{-\pi} = \frac{1}{\pi} \approx 0.318$
    *   $h[3] = h[7] = \frac{\sin(-\pi)}{-2\pi} = 0$
    *   $h[2] = h[8] = \frac{\sin(-1.5\pi)}{-3\pi} = \frac{1}{-3\pi} \approx -0.106$
    *   $h[1] = h[9] = 0$
    *   $h[0] = h[10] = \frac{\sin(-2.5\pi)}{-5\pi} = \frac{-1}{-5\pi} \approx 0.064$

**9. 如何用窗函数法设计线性相位FIR高通、带通或带阻滤波器？**

**答案：**
原理与低通相同，区别在于**理想脉冲响应 $h_d[n]$ 的公式不同**：
1.  **高通：** $h_{HP}[n] = \delta[n-\tau] - h_{LP}[n]$ （其中 $h_{LP}$ 截止频率为 $\omega_c$）。
2.  **带通：** $h_{BP}[n] = h_{LP\_high}[n] - h_{LP\_low}[n]$ （两个低通之差）。
    或者：$h_d[n] = \frac{\sin[\omega_{c2}(n-\tau)] - \sin[\omega_{c1}(n-\tau)]}{\pi(n-\tau)}$。
3.  **带阻：** $h_{BS}[n] = \delta[n-\tau] - h_{BP}[n]$。
确定 $h_d[n]$ 后，同样乘以窗函数 $w[n]$ 即可。

**10. 判断题：**

1.  窗口法设计出的线性相位FIR DF是因果稳定的。（ **正确** ）
2.  线性相位FIR DF窗口设计法的关键是窗口大小。（ **正确** ）
    *   *解析：窗口大小直接决定了过渡带的宽度，是满足指标的关键参数。*
3.  矩形窗口法设计线性相位的FIR数字滤波器时，增加窗口宽度可以增加正肩峰的大小。（ **错误** ）
    *   *解析：增加窗口宽度 N 只能减小过渡带宽度，肩峰（过冲）大小主要取决于窗函数的类型（形状），矩形窗始终约为 9%。*
4.  用矩形窗设计线性相位的FIR低通滤波器，主瓣宽度越小，过渡带宽（ **越小** ）。
    *   *解析：主瓣宽度与 N 成反比，过渡带宽度与主瓣宽度成正比。主瓣越窄，过渡带越陡峭（越窄）。*
